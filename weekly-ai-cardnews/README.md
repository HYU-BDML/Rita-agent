# 주간 AI 소식 카드뉴스

주차 하나만 고르면 그 주 AI 소식을 모아 인스타 카드뉴스로 만들어 줍니다.
**새 분야**에서는 보고 싶은 소식(아이돌·주식·회사 등)을 말로 정하면, 지휘자 AI가 X · 인스타그램 · 스레드 · 웹 · 기사를 직접 찾아 들어가 그 기간 소식을 원문 증거와 함께 모아 줍니다.

## 바로 쓰기

👉 **https://weekly-ai.david112702.workers.dev** · 리타(RITA)에서는 「주간 AI 소식 만들기」 에이전트

위 주소를 열면 설치 · 가입 · 열쇠 없이 바로 씁니다. 맨 위 칩에서 분야를 고릅니다 — **AI 소식** · 저장된 분야들 · **＋ 새 분야**.

### AI 소식

1. **주차**를 고릅니다. 최근 12주 가운데서 고를 수 있습니다.
2. **만들기**를 누릅니다. 10~15분쯤 걸립니다. 창을 닫아도 계속 만들어지고, **지난 결과** 목록에서 다시 볼 수 있습니다.
3. 다 되면 넘겨보기가 뜹니다. **주소 복사**나 **새 창으로**로 공유합니다.
   도중에 멈추면 이유가 나오고, **이어서 다시**를 누르면 멈춘 단계부터 이어서 만듭니다.

### 새 분야

1. **＋ 새 분야**를 누르고 보고 싶은 소식을 말합니다. 예: «코르티스 이번 주 소식», «엔비디아 주가 지난주 소식».
2. 지휘자 AI가 필요한 만큼만(보통 1~3번) 되묻고 **주문서**(주제 · 범위 · 기간 · 넣을 것 · 뺄 것 · 목표 건수 · 찾는 넓이)를 보여 줍니다. 고칠 점은 말로 적어 보냅니다.
3. **이대로 모으기**를 누릅니다. 10~40분쯤 걸립니다. 모으는 동안 지금 단계 · 지휘자 판단 · 남은 예산 · 걸음마다 쓴 돈이 흐릅니다. 창을 닫아도 계속 모읍니다.
4. 다 되면 **소식 묶음**이 뜹니다 — 소식마다 사진·영상, 요약, 원문 링크, 원문 발췌, «2차 출처»·«불확실» 딱지. 못 채운 칸과 그 이유, 빠진 소식과 그 이유, 도중에 끈 도구도 함께 나옵니다.
5. 결과가 마음에 들면 **«…» 분야로 저장**을 누릅니다. 맨 위 칩에 생기고, 다음부터는 대화 없이 **기간만 골라** 다시 모읍니다. 저장한 분야는 모두에게 보입니다.

한 번에 모을 수 있는 새 분야는 **동시에 2판, 하루 10판**까지입니다. 자료 모으기 분량이 거의 다 떨어지면 새 분야는 잠시 쉬고, AI 소식은 그대로 됩니다.

## 하는 일

### AI 소식

1. **소식 모으기** — ChatGPT · Claude · Gemini · Cursor · Perplexity · Meta AI · NVIDIA 일곱 곳이 그 주에 X · 스레드에 올린 글과 공식 블로그 글을 모읍니다.
2. **소식 고르기** — 회사마다 소식 하나를 고르고, 올린 계정의 평소 반응보다 크게 터진 소식부터 순서를 정합니다. 첫 소식의 회사가 표지 주인공이 됩니다.
3. **대본 쓰기** — 소식마다 헤드라인 두 줄과 본문 세 줄, 그리고 표지 문구를 씁니다. 글자 수 · 카드 폭 · 말투 규칙에 어긋나면 두 번까지 다시 씁니다.
4. **카드 만들기** — 소식에 딸린 사진 · 영상을 쓰고, 없으면 그림을 만들어 카드로 굽습니다. 표지 + 소식 + 마무리 카드 순서입니다.

### 새 분야 — 지휘자

정해진 순서 대신 **생각의 사슬**을 줍니다. 지휘자(DeepSeek)는 «생각 → 행동 → 관찰 → 판단» 고리를 돌며 일곱 단계(① 이해하기 ② 지도 그리기 ③ 넓게 훑기 ④ 들어가 보기 ⑤ 단서 따라 깊게 ⑥ 빈칸 점검 ⑦ 증거 다지기)와 생각 원칙 13개로 스스로 판단하고, 판단이 바뀔 때마다 **작업판**에 적습니다.

- **도구 11개** — 작업판 적기 · 웹 검색 · X 검색 · X 계정 · 인스타 검색 · 인스타 계정 · 스레드 계정 · 기사 읽기 · 사진 판정 · 증거 다시 보기 · 결과 내기. 도구 이름과 결과 모양은 고정이고, 뒤에서 쓰는 Apify 도구는 **도구 장부**(`server/topic/registry.json`)에서 바꿔 끼웁니다.
- **증거** — 도구 결과마다 증거 번호(E1, E2 …)가 붙고, 요약 문장마다 그 번호를 답니다.
- **관문** — 결과를 내면 코드가 검사합니다: 증거 번호가 이 판의 것인가, 발췌가 원문에 글자 그대로 있나, 날짜가 기간 안인가, 요약의 숫자가 발췌에 있나, 미디어가 그 글의 것인가, 같은 사건이 둘인가, «못 찾았다» 는 곳을 정말 찾아봤나. 걸리면 고치라고 돌려보내고, 세 번 뒤에도 그대로면 그 소식을 빼고 까닭을 남깁니다.
- **예산** — 찾는 넓이(A 좁음 · B 보통 · C 넓음)마다 도구 20 · 50 · 100번, $1 · $2 · $4, 40분까지. 같은 도구를 같은 인자로 다시 부르지 않고, 예산이 끝나면 모은 것으로 결과를 냅니다.
- **미디어** — 영상 → 사진 → 없음 순서. 영상은 공식 계정의 글에 붙은 것을 그대로 쓰고, 기사 사진은 사진 판정이 «장면» 이라 한 것만 씁니다.

## 만든 것

| 맡은 일 | 쓰는 것 |
|---|---|
| 화면 | Cloudflare Workers |
| 흐름 지휘 · 지난 결과 보관 | AWS Lambda · S3 |
| 대본 쓰기 · 새 분야 지휘 · 주제 다듬기 | DeepSeek `deepseek-v4-pro` |
| 문장 · 사진 판정 | DeepSeek `deepseek-flash` |
| 소식 모으기 | Apify (X · 인스타그램 · 스레드 · 구글 검색) · 각 회사 공식 블로그 |
| 기사 본문 뽑기 | trafilatura |
| 그림 만들기 | OpenAI GPT Image 2.5 |
| 카드 굽기 · 넘겨보기 | AWS Lambda |

## 코드

| 폴더 | 하는 일 |
|---|---|
| `web/` | 화면(Cloudflare Workers). `/api/*` 를 지휘 서버로 넘긴다 |
| `server/` | 지휘 서버(AWS Lambda) — AI 소식은 소식 → 본문 → 표지 → 그림 → 굽기 다섯 단계 |
| `server/nodes/` | 소식 고르기 · 본문 검사 · 표지 검사 · 대본 합치기 |
| `server/topic/` | 새 분야 — 주문서 · 도구 11개 · 지휘자 · 관문 · 판정관 · 예산 · 작업판 · 판 달리기(모으기 · 검증 · 정리) |
| `oldserver_patch/` | 카드 굽기 서버에 얹는 고침(표지 그림 · 소식 명단 · 블로그) |
| `tests/` | 시험 (`python -m pytest tests`, `node --test "web/test/*.test.js"`) |
| `원본/` | 옮기기 전 Dify 워크플로우 원본 |

공개 저장소라 서버 주소 · 계정 번호는 `<지휘 서버 주소>` · `<옛 서버 주소>` · `<S3 통 이름>` · `<AWS 계정 번호>` 같은 빈칸으로 바꿔 두었습니다. 직접 돌리려면 자기 값으로 채워 넣으세요. 열쇠(DeepSeek · OpenAI · Apify)는 코드에 없고 환경변수(`DEEPSEEK_API_KEY` · `OPENAI_API_KEY` · `APIFY_TOKENS`)로만 받습니다. 실제로 긁은 소식 자료(`tests/재료/`)는 올리지 않아 그 자료를 쓰는 시험은 이 사본에서 돌지 않습니다.
