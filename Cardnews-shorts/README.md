# 카드뉴스 숏츠 스튜디오

작성 2026-10-16 · Rita 에이전트 · 대상: 수업 학생(사용), 교수·조교(관리·수정), 개발 담당(배포)

카드뉴스 이미지나 직접 만든 그림에 장마다 내레이션을 쓰면, 자막과 AI 목소리가 들어간 세로 숏츠(1080×1920, 9:16) mp4가 나온다. 학생이 만든 숏츠는 프로젝트마다 소스(설계도·그림·음성)가 자동 저장되어, 교수가 나중에 한 장면만 고쳐 다시 만들 수 있다.

## 화면 구성의 근거

조회수가 높은 정보형 쇼츠 18건(한국어 13건, 영어 5건)을 조사하고, 그중 9건을 계측해 화면 규칙을 정했다(조사 문서: 작업 폴더의 shorts_research.md).

| 계측한 내용 | 고조회 쇼츠 9건 | 이 에이전트 |
|---|---|---|
| 첫 음성 시작 | 9건 모두 0.36초 이내 | 0.12초 |
| 평균 장면 길이 | 5건이 1.25~2.72초 | 약 2.1초(자막 구절이 바뀌는 시각에 컷) |
| 상단 제목 | 한국어 4건이 영상 끝까지 고정 | 노란색·흰색 2줄 고정 |
| 자막 | 8건이 상자 없이 흰 글씨와 검은 테두리, 한 구절씩 | 같은 방식, 숫자와 *별표* 단어는 노란색 |
| 통합 음량 | 중앙값 −13.2 LUFS | −14 LUFS로 맞춤 |

화면 형식은 두 가지다. 제목 띠형(기본)은 위쪽 제목, 가운데 그림, 그림 아래 자막으로 구성되어 카드뉴스 이미지에 알맞다. 전체 화면형은 사진이 화면 전체를 채우고 자막이 가운데에 뜨며, 카드 장면만 제목과 자막 사이 칸에 놓인다.

## 품질 장치

1. 숫자는 음성에 보낼 때만 한글 읽기로 바꾼다. "Landon 54%"를 "랜던 오브 사퍼런"으로 읽던 오류가 시험에서 실제로 나와 넣었다. 자막에는 원래 숫자가 그대로 나온다.
2. 문장마다 음성을 만든 직후 Whisper로 받아 적어 원고와 비교한다. 일치율이 0.90 아래면 최대 두 번 다시 만들고, 그래도 낮으면 학생 화면에 "N장 발음 확인 필요"를 띄운다.
3. 만들기 전 검사(무료)로 카드 수 3~12장, 장당 160자 이하, 전체 90초 이하, 상단 제목 유무를 확인한다.
4. AI 이미지(나노바나나 프로, 2K)는 글자를 넣지 않게 지시한다. AI가 그린 한글은 깨지기 쉬워서, 글자는 카드와 자막이 맡는다.

## 소스 저장과 부분 수정

프로젝트 폴더 하나가 숏츠 한 편의 소스다.

| 위치 | 내용 |
|---|---|
| project.json | 상단 제목, 화면 형식, 장면 순서, 장별 내레이션·그림, 목소리, 속도, 배경음악, 발음 사전 |
| cards/ | 장면 그림 원본(학생이 올린 것과 AI로 만든 것) |
| ai_images.jsonl | AI 그림을 만든 설명문 기록 |
| history/ | 저장할 때마다 남는 이전 판 project.json |
| cache/tts/ | 문장별 음성과 발음 검사 결과 |
| out/video.mp4 | 완성 영상 |

교수가 일부만 고치는 방법은 두 가지다. 첫째, /admin 목록에서 «열기»를 눌러 그 장의 내레이션이나 그림만 바꾸고 «다시 만들기»를 누른다. 둘째, «소스 받기»로 압축 파일을 받아 project.json을 고친 뒤 /admin의 «소스 올리기»로 새 프로젝트로 연다. 두 경우 모두 바뀐 장면만 새로 만들고 나머지는 캐시를 쓴다. 시험에서 4장짜리 영상의 3장만 고쳤을 때 46초 걸리던 작업이 18초로 줄었다.

## 경계

| 대상 | 볼 수 있는 것 | 확인한 요청과 결과 |
|---|---|---|
| 학생 | 자기 프로젝트 주소(추측할 수 없는 32자 번호)로 연 프로젝트만 | 다른 번호 404, 폴더 밖 경로 4종 404 |
| 교수·조교 | ADMIN_TOKEN을 넣은 /admin에서 전체 목록, 소스 받기·올리기 | 열쇠 없음 403, 틀린 열쇠 403 |

## 실행

로컬: `pip install -r requirements.txt && python app/get_fonts.py && python app/studio.py` 후 http://127.0.0.1:8090 을 연다. 키는 환경 변수 FAL_KEY(없으면 ~/.config/llmgw/.env)에서 읽는다.

배포: render.yaml로 Render에 올린다. 대시보드에서 FAL_KEY와 ADMIN_TOKEN을 직접 넣고, /data 디스크(20GB)를 붙여야 학생 프로젝트가 재시작 뒤에도 남는다. Docker 이미지에서 5장 36.4초 영상이 116초 만에 만들어지는 것을 확인했다.

다시 만들기: `python tools/render_project.py <소스 폴더>`

## 비용이 드는 호출(fal.ai)

| 호출 | 언제 | 비고 |
|---|---|---|
| ElevenLabs multilingual-v2 음성 | 문장마다 1회(같은 문장·목소리면 다시 쓰지 않음) | 발음 검사에서 어긋나면 최대 2회 더 |
| Whisper 받아 적기 | 음성을 만들 때마다 1회 | 끄려면 VERIFY_SPEECH=0 |
| 나노바나나 프로 이미지 | 학생이 AI 그림을 누를 때 | 프로젝트당 30장 상한 |

호출당 금액은 fal.ai 요금표로 확인해야 한다(이 문서에는 적지 않았다). 영상 만들기는 프로젝트당 30번이 상한이다.
