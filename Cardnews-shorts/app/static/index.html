카드뉴스 숏츠 스튜디오

카드뉴스 이미지와 장별 내레이션으로 자막·음성이 들어간 세로 숏츠(9:16)를 만듭니다

새 숏츠 시작

학번·이름과 제목을 적고 시작하세요. 작업은 자동으로 저장되고, 이 브라우저의 «내 작업»에 남습니다.

fal.ai 키 넣기 키 없음

음성·발음 검사·AI 그림은 각자의 fal.ai 계정으로 만들고 비용도 그 계정에서 나갑니다. 대본 만들기(Gemini)는 수업에서 부담하므로 키가 필요 없습니다.

  1. 가입 · fal.ai 열기 구글 또는 GitHub 계정으로 로그인합니다.
  2. 크레딧 확인 · Billing 열기 잔액(Credits)이 0이면 충전합니다. 잔액이 없으면 키가 맞아도 만들기가 실패합니다. 5장짜리 숏츠 한 편(AI 그림 10장)은 약 $1.6이 듭니다(그림 장당 $0.15, 음성 1,000자당 $0.1, 2026-10-16 fal.ai 요금표 기준). 직접 만든 그림을 올리면 그림 비용은 들지 않습니다.
  3. 키 만들기 · Keys 열기 Create Key → 이름 입력(예: shorts) → 권한 API → 만들어진 키를 바로 복사합니다. 이 창을 닫으면 키를 다시 볼 수 없습니다.
  4. 붙여 넣고 확인 · 아래 칸에 붙여 넣고 «키 확인»을 누릅니다(비용 없음).

키는 이 브라우저에만 저장되고, 서버는 영상을 만드는 동안에만 쓰며 파일로 남기지 않습니다. 다른 사람에게 키를 보내지 마세요.

이 작업의 주소를 저장해 두면 다른 컴퓨터에서도 이어서 할 수 있습니다:

0AI로 대본 만들기(선택)

주제와 참고 자료를 넣으면 AI(Gemini)가 상단 제목, 장별 내레이션, 장면 그림 설명을 씁니다. 참고 자료에 있는 사실만 쓰게 하고, 자료에 없는 숫자는 «확인 필요»로 표시합니다. 만든 대본은 판마다 저장되어 언제든 다시 적용할 수 있습니다.

저장된 대본 판

1장면 이미지 넣기

이미지 한 장이 한 장면이 됩니다(3~12장). 카드뉴스 이미지(4:5·1:1)와 직접 만든 사진·AI 이미지 모두 쓸 수 있습니다. 나노바나나 등에서 만든 그림은 글자 없이 만들어 오세요.

이미지를 여기에 끌어다 놓거나

2장마다 내레이션 쓰기

한 장에 1~2문장(40~90자), 전체 300자 안팎(약 50초)이 알맞습니다. 쓴 문장이 그대로 자막이 되고 AI 목소리가 읽습니다. 숫자는 자동으로 노란색이 되고, 강조할 말은 *별표*로 감싸면 노란색이 됩니다. 장면마다 그림을 2~3장 넣으면 화면이 2~3초마다 바뀌어 더 잘 봅니다.

아직 장면이 없습니다. 1단계에서 이미지를 넣으세요.

3목소리와 배경음악

저작권 문제가 없는 음악만 쓰세요(YouTube 오디오 보관함, CapCut 무료 음악 등). 내레이션이 나올 때는 음악 소리가 자동으로 줄어듭니다.

발음 고치기(영어 이름·약어를 다르게 읽을 때)

한 줄에 하나씩 «원래 글자=읽을 소리»로 적습니다. 예: Literary Digest=리터러리 다이제스트. 자막은 원래 글자 그대로 나옵니다.

4검사하고 영상 만들기

영상 내려받기(mp4)

고칠 곳이 있으면 위에서 그 장만 고친 뒤 다시 «영상 만들기»를 누르세요. 바뀐 장면만 새로 만들어 빨리 끝납니다.

소스(편집용 파일 묶음) 내려받기

좋은 숏츠를 위한 다섯 가지

  1. 첫 장 내레이션은 질문이나 놀라운 숫자로 시작하세요. 사람들은 첫 3초에 넘길지 정합니다.
  2. 한 장에 메시지 하나만 담으세요. 자막이 두 화면을 넘으면 장을 나누세요.
  3. 숫자는 비교 대상과 함께 말하세요(예: «예측은 54%, 실제는 60.8%»).
  4. 장면마다 그림을 2~3장 넣으세요. 조회수가 높은 정보 숏츠는 화면이 평균 1.3~2.7초마다 바뀝니다.
  5. AI 이미지에는 글자를 넣지 마세요. 글자는 카드와 자막이 맡습니다.
  6. 마지막 장은 보는 사람이 할 행동 하나로 끝내세요.

AI로 장면 이미지 만들기

장면을 구체적으로 설명하세요(누가, 어디서, 무엇을, 어떤 분위기). 영어로 쓰면 더 정확합니다. 한 장에 30초 안팎 걸립니다.
