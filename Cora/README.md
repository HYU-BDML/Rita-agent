# Cora

**Content Operations Run by Agents** — 추후 변경 가능한 제품명.

Cora 전용 개발 공간이다. 본인과 조유경 학생이 AI와 12주 동안 합의한 출시 범위의90% 이상을 구현하는 것이 목표다. 개발자는 출시 전 독립 검토와 미해결 문제 보완을 맡는다.

## 폴더

- `apps/trend-hub/`: 기존 Trend ZIP에서 복사한 수정 가능한 앱 기반. 아직 Cora UI로 전환하거나 실행 검증하지 않았다.
- `integrations/cardnews/`: 배포 링크와 코드 입수 후 통합할 자리.
- `docs/제품개발_마스터플랜_2026-09-29/00_여기부터.md`: 현재 사업·제품·12주 개발계획.
- `docs/`: Mirr 분석, 국내외 벤치마크, 연구 및 사업계획. 과거 전략 문서는 당시 기록이며 현재12주·90% 구현 원칙이 우선한다.
- `research/`: 조사 메모·공개 페이지 캡처·문서 생성/검증 스크립트의 보관본. 과거 생성 스크립트에는 기존 로컬 경로가 있어 실행 전 경로를 조정해야 한다.
- `references/trend-hub/`: 가져온 앱의 과거 설계·지시서. 현 프로젝트 실행 지침이 아닌 참고 자료다.
- `PROVENANCE.json`: 복사 원본·커밋·파일 해시.
- `CHANGELOG.md`: Cora의 변경 이력.

## 작업 방식

원래 Rita-agent의 Trend/cardnews/Smartstore/숏폼 폴더는 수정하지 않는다. 재사용하는 코드는 Cora 안으로 복사하고 이곳에서 변경한다. 원본 개선을 가져올 때는 차이를 검토하고 선택적으로 반영한다. 원본으로부터 자동 덮어쓰기는 하지 않는다.

코드·문서의 변경은 작업 브랜치에서 커밋하고 PR로 비교한다. 기존 Google Drive 작업공간은 로컬 보관과 산출물 열람에 계속 사용하며, GitHub의 Cora 폴더에서 버전 이력을 관리한다. Drive outputs로 내보낼 때도 같은 변경을 Cora/docs에 반영한다. 비밀키·고객 파일·운영 DB·생성 결과물은 Git에 넣지 않는다.

## 앱 실행 준비

Node.js 20.9 이상이 필요하다. `cd Cora/apps/trend-hub` 후 `npm ci`, `npm run dev`로 시작하며 기본 포트는3100이다. API 연동은 `.env.example`의 항목을 로컬 환경에 설정한다. 키 없는 모드는 실제 생성 성공과 구분한다.

이번 초기 이관에서는 설치·빌드·실행·유료 API 호출을 수행하지 않았다. 원본의13MB data/db.json은 실행 데이터이므로 복사하지 않았다. 기존 tests/recipe.test.ts의 한 시험은 해당 데이터에 의존하므로 전체 테스트 전에 명시적인 시험 fixture로 전환해야 한다. 앱을 실행해 새 data/db.json이 생겨도 Git에서는 제외된다.
