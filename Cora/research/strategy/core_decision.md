# 사업 방향 초안과 반증 조건

## 현재 판단

Mirr보다 기능이 많은 범용 콘텐츠 자동화 SaaS를 곧바로 만드는 것은 추천하지 않는다. 첫 고객은 사용자가 확정한 소규모 SNS 콘텐츠 대행사로 유지하되, 다음 납품 업무 한 가지를 기존 도구보다 잘 끝내는지 8주 동안 검증한다. 이미 있는 도구와 Claude 자산을 사용해 서비스 형태로 실제 결과를 전달하고, 반복해서 돈을 내는 부분만 제품화한다. 검증이 안 되면 독립 SaaS 개발을 멈추고 재사용 가능한 모듈만 Rita에 남긴다.

이는 성공 확률을 숫자로 추정한 결과가 아니다. 지금은 고객 인터뷰·구매·갱신 증거가 없어 전면 투자 판단을 할 수 없다는 뜻이다. 기존 기능 조사와 제품 시안은 준비됐으나 시장 검증은 아직 안 됐다.

## 좁힐 상품

고객사 한 곳의 소개 자료·기존 게시물·이번 주 요청을 입력하면, 브랜드 규칙과 출처를 붙인 다음 주 기획안, 편집 가능한 카드뉴스 초안, 고객 검토 화면을 제공한다. 첫 시험 범위는 브랜드 1개, 카드뉴스 1개, 캡션 1개, 수정 1회다. 실제 납품 후 같은 브랜드의 다음 작업에서 다시 쓰는지 확인한다.

자동 발행·대시보드는 이어질 방향이지만 첫 수요 실험의 필수 전제는 아니다. 처음부터 계정 연결·API키 발급·워크플로 구성·전체 고객사 이전을 요구하지 않는다. 사용자가 제공한 자료로 결과부터 보여준다. 게시물 이미지로는 실제 도달·저장·매출을 알 수 없으므로 수치를 만들지 않는다.

## 경쟁이 이미 제공하는 것

Buffer의 API/MCP, Planable의 브랜드 맥락·승인, Canva/미리캔버스 기업용의 브랜드·검토, NHN 소셜비즈의 계정 진단·운영 리포트가 존재한다. 한국어, 자동화, 브랜드 규칙, 승인, 분석은 기능 범주 자체로 독점적인 강점이 아니다. 우리 강점은 동일 업무의 채택률·총작업시간·오류·비용으로 검증해야 한다.

## 자원 조건

학생 2~3명, 1인당 주4~5시간으로 해석하면 팀 전체 주8~15시간, 8주64~120시간이다. 프로그래밍 가능 학생도 포함된다. 이는 기존 자산으로 소규모 실험을 하기 위한 규모이며 전체 상용 SaaS를 안정 운영할 인력 계획은 아니다. 첫 단계 현금 지출은 30만원 상한으로 제안하되 확정·집행하지 않는다. API·실행10만원, 호스팅·저장5만원, 모집·인터뷰실비5만원, 예비10만원. 학생 인건비·사용자 시간·디자이너 외주·기존 구독비는 별도다. 유료 디자인 검수가 필요하면 견적 확인 후 별도 증액한다.

## 검증 계획

1~2주: 대행사 실제 작업 인터뷰6곳, 자료를 보여주는 곳3곳, 같은 병목이2곳 이상인지 확인한다. 크리에이터2명은 확장 가능성을 관찰하는 비교군이며 동시에 두 제품을 만들지 않는다.

3~4주: 대행사2곳에 각 브랜드1개, 카드뉴스1개를 기존 자산으로 제작해 기존 방식과 비교한다. 실제 시간·수정 이유·최종 채택을 기록한다. 기계 생성과 사람 보정 시간을 모두 합친다. 파일럿 가격은 예컨대 브랜드1개·카드뉴스1개·캡션·수정1회당5만원이라는 테스트 제안을 사용하되, 시장 적정가격이나 확정 판매가로 주장하지 않는다. 고객 인터뷰 후 범위와 함께 고지하고 계약·입금 전에는 매출로 세지 않는다.

5~8주: 같은 조건으로 다음 주/다음 달 납품에 재사용·재결제가 일어나는지 확인한다. 2곳 중2곳 실제사용·독립적인 재결제, 전체작업시간 중앙값30%감소, 추가 운영지원 고객당 주30분 이내, 직접비+사람보정비를 포함한 기여이익 양수를 다음 투자 검토 기준으로 제안한다. 같은 팀 안 콘텐츠 수를 독립 고객 표본으로 세지 않는다. 이 작은 표본은 PMF나 시장 대표성의 증거가 아니다. 통과하면 독립 고객5~10곳으로 검증을 확장한다.

## 중단 조건

2주 안 모집 실패면 채널·제안문을 한 번 수정하고1주 추가; 그래도 실제 자료를 주는 대행사2곳이 없으면 제품 개발을 확대하지 않는다. 모집 실패는 수요 부재로 단정하지 않지만 현재 팀의 시장 접근 문제로 본다. 첫 결과가 채택되지 않으면 실패 이유를 바탕으로 한 차례 수정; 반복 실패면 생성 범위를 축소하거나 중단한다. 할인·보조·무료 대행을 빼면 재결제가 없거나 사람 보정비로 손해면 SaaS 확장 판단을 미룬다. 기준 변경은 판정 전에 이유를 남긴다.

## 크리에이터 확장과 Rita

크리에이터는 단순 가입 수보다 반복 제작·상업 활동·유료 문제를 기준으로 선택한다. 코칭·교육·서비스 판매처럼 콘텐츠가 실제 사업에 연결되는 크리에이터가 비교 후보지만 수요 검증은 별도다. 계정 진단 보고서만 제공하는 제품은 경쟁과 무료 대안이 강하다. 진단 뒤 실제 다음 콘텐츠가 만들어지고 운영시간이나 전환 측정이 개선되는지 검증한다.

Rita에는 소재 수집, 제작 지시서, 브랜드 검수, 렌더, 승인, 발행, 결과 수집을 분리해서 넣을 수 있다. 고객별 데이터·승인·실행비용·결과 ID를 보관한다. 모델 호출 로그는 생성 원가만 증명하며 판매·납품·조회·구매는 별도 증거다. 대행사 서비스의 유료 사용이 Rita 전체 에이전트 시장의 성공을 뜻하지는 않는다.
