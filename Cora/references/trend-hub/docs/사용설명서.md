## 1. 찾기 — 탐색 화면

### 검색

가운데 검색창에 치시면 됩니다. **이미 모아 둔 후보에서 찾습니다.**

- **이름 말고 별명으로도 찾힙니다.** `배드 챌린지`로 치면 `BAD 챌린지`가,
  `코리락쿠마`로 치면 `리락쿠마`가 나옵니다
- 설명과 근거 기사 본문까지 훑습니다
- **추적 중인 소재도 같이 나옵니다**

> 지금은 **모아 둔 것 안에서만** 찾습니다. 검색할 때마다 외부 플랫폼에 물어보지
> 않습니다 — 그러면 칠 때마다 돈이 나갑니다. 외부에서 새로 찾는 기능은 다음 단계입니다.

### 분야와 세부 갈래

검색창 아래 단추로 분야를 고르면, **그 분야의 세부 갈래**가 한 줄 더 나옵니다.

```
[전체]  [뉴스·사건]  [캐릭터·굿즈]  [유행 포맷]
              ↓ 분야를 고르면
뉴스   → 정치 · 경제·산업 · 사회 · 국제 · 연예·문화 · 스포츠·게임 · 과학·기술 · 마케팅·광고
캐릭터 → 기업 IP · 개인 창작 · 권리 분쟁 · 기타
포맷   → 챌린지 · 유행 형식 · 유행어·말 · 기타
```

`마케팅·광고`는 이 도구에서 제일 쓸모 있는 갈래입니다 — 광고 전문지에서 온 소재가
일반 경제 뉴스에 묻히지 않게 따로 세웠습니다.

**캐릭터의 `권리`는 만들어도 되는지를 가릅니다.**

- `기업 IP` — 라이선스가 필요합니다
- `개인 창작` — 원작자 허락을 확인하면 만들 수 있습니다
- `권리 분쟁` — 누구 것인지 다툼이 있습니다. **손대지 마세요**
- `기타` — 아직 못 가렸습니다

## 2. 골라서 지켜보기 — 추적

마음에 드는 후보의 **`보관하고 추적하기`** 를 누르면 `추적 중`으로 넘어갑니다.

즐겨찾기가 아닙니다. **그때부터 자동으로 지켜봅니다** — 매일 뉴스를 훑어 그 소재에
관한 새 기사를 찾아 근거에 붙입니다. `추적 중` 화면에서 마지막 확인 시각과
쌓인 근거를 보실 수 있습니다.

그만 보고 싶으면 **`추적 중지`** 를 누르시면 됩니다.

## 3. 새로 찾기 — 수집 돌리기

탐색 화면 아래쪽 `새로 찾기` 줄에 분야별 단추가 있습니다.

| 단추 | 걸리는 시간 | 무엇을 하나 |
|---|---|---|
| 뉴스 소재 돌리기 | 약 40초 | 뉴스 9곳을 훑어 여러 매체가 함께 다루는 주제를 찾습니다 |
| 캐릭터 발굴 돌리기 | 약 6분 | 인스타·X·틱톡·유튜브에서 캐릭터를 찾고 권리를 판정합니다 |
| 밈 발굴 돌리기 | 약 8분 | 따라 하는 사람이 여럿인 유행 포맷을 찾습니다 |

### 돌리기 전에 아셔야 할 것

- **한 번에 1,500~2,000원쯤 듭니다.** 외부 API 요금입니다. 자주 누르는 단추가 아닙니다
- **창을 닫지 마세요.** 도는 동안 진행 막대가 보입니다
- 단추 아래 **`오늘 N회 남았습니다`** 가 하루 한도입니다.
  분야마다 3회씩이고, **한국시간 자정에 다시 열립니다**
- 한도를 다 쓰면 **단추가 잠깁니다. 고장이 아닙니다**

## 4. 알아두실 것

### 사진이 없는 카드가 있습니다

정상입니다. 틱톡 사진 주소는 며칠이면 만료됩니다. 그럴 때 깨진 그림을 보여 주는
대신 **사진 자리를 없애고 글만 남깁니다.** 새로 수집하면 다시 채워집니다.

유튜브 사진은 만료되지 않아서, 회차를 돌릴수록 사진이 남는 카드가 늘어납니다.

### 눌러 본 것이 남지 않을 수 있습니다

무료 서버는 저장 공간을 못 붙입니다. **프로그램을 새로 올리면 데이터가 처음
상태로 돌아갑니다** — 눌러 두신 `추적 중` 목록이나 새로 돌린 회차가 사라집니다.
남겨야 한다면 유료 플랜으로 올려야 합니다.

### 안 보이는 것이 있습니다

- **트렌드 레이더** — 별도 프로그램이 남긴 파일을 읽는 판정기라 이 서버에는 없습니다.
  이미 쌓인 레이더 후보는 목록에 그대로 보입니다
- 안전 문제로 제외한 후보는 목록에서 뺐습니다. 왜 뺐는지는 **설정** 화면에서 보실 수 있습니다

## 5. 다른 프로그램에 넘기기

```
GET /api/brief?scope=character&limit=3
```

쌓인 후보를 JSON으로 내보냅니다. **외부 API를 부르지 않아 돈이 안 듭니다.**
`scope` 는 `issue` · `character` · `meme` 중 하나입니다(쉼표로 여러 개도 됩니다).
결과는 `topics` 배열로 나옵니다. `limit` 은 최대 10입니다.
