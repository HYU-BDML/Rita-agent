# UI 재설계 + 회차 자동 실행 지시서

대상: 3100 (Next.js / TypeScript)
작성일: 2026-09-19

---

## 0. 작업 방식

기존 `docs/재설계-지시서.md` 0장의 규칙을 그대로 따른다.

- 단계마다 멈추고 보고한다
- 고치기 전에 `[현재] / [제안] / [영향] / [확인]` 으로 먼저 보여준다
- 최소 변경. 파일 통째 재작성 금지
- 삭제 대신 비활성
- 문서와 코드가 어긋나면 코드가 맞다. 어긋난 지점을 보고할 것

이 문서는 **화면만** 다룬다. 판정 로직·수집·계약 JSON 은 건드리지 않는다.

## 1. 디자인 토큰

RITA 로고에서 뽑은 색이다. 한 곳에 상수로 두고 쓴다.

```
--ink      #15163a    상단 바 배경
--blue     #3340dc    선택된 칩, 링크
--grad     linear-gradient(135deg, #4a4ee8 0%, #7b52e0 55%, #a94fd6 100%)
--sel      #eef0fd    선택된 카드 배경
--selbd    #cfd5f6    선택된 카드 테두리
--line     #e7e6ef    기본 테두리
--line2    #f0eff5    카드 안쪽 구분선
--mute     #84839a    보조 텍스트
--dim      #a9a7bc    흐린 텍스트
--body     #f6f6fa    페이지 배경
```

**그라데이션은 네 군데만 쓴다.** 상단 바 아래 2px 선 · 확정 배지 · 브랜드 마크 · 주 버튼. 더 늘리면 데이터가 안 보인다.

개인 창작 배지만 자홍 계열이다 — 배경 `#fae6f7` · 글씨 `#8f2a86`. 초록은 팔레트 밖이라 쓰지 않는다.

### 글꼴

Pretendard 로 바꾼다.

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/dist/web/variable/pretendardvariable.min.css">
```

```css
font-family: "Pretendard Variable", Pretendard, -apple-system, "맑은 고딕", sans-serif;
letter-spacing: -.01em;
```

숫자에는 `font-variant-numeric: tabular-nums` 를 준다. 안 주면 자릿수가 어긋나 지저분해 보인다.

## 2. 목록 페이지 구조

폭은 `max-width: 1140px`, 좌우 여백 32px.

```
상단 바 (검정, 아래 2px 그라데이션)
회차 상태 줄
──────────────────
오늘 들어온 것  3건
  새로 잡혔거나 등급이 오른 것만 올립니다
  [카드 3개 · 3칸 격자]
──────────────────  (구분선)
전체  68건                       조회수 순
  어디서 온 캐릭터인지로 갈랐습니다
  [출신 칩]
  [카드 6개 · 3칸 격자]
  [더 보기 — 62건 남음]
  [담아둔 것 — 지난 회차에서 고른 7건]
──────────────────
하단 고정 담기 바
```

### 왜 3칸인가

4칸은 설명 한 줄이 들어갈 폭이 안 나오고, 가로 한 줄 배치는 너무 길어서 정보가 많아 보인다. 3칸이 중간이다. 바꾸지 말 것.

### 회차 상태 줄

목록 맨 위. 흰 카드 한 줄.

```
● 월·수·금 오전 8시에 알아서 찾습니다    마지막 09-19 05:02 · 다음 09-21 08:00   바꾸기
```

초록 점 `#3fb27a` · 7px. 자동이 꺼져 있으면 회색 점에 "자동 실행 꺼짐 · 켜기".

## 3. 카드 구조

다섯 층이다. 순서를 바꾸지 말 것.

```
┌─────────────────────────┐
│ [썸네일 큰 것 1 | 작은 것 2]  126px, 우하단에 "23장"
├─────────────────────────┤
│ 치이카와  [확정 4일] [기업 IP]      이름 16px 600 + 배지
│ CU 편의점 신상 별사탕 2탄이 …       설명 13px, 2줄, min-height 41px
│ [애니·만화] [9월에 두 배]           태그 알약 11.5px
│ ──────────────────────  실선
│ 계정 4곳   조회 81,683              12px, 값만 600
└─────────────────────────┘
```

- 썸네일: `grid-template-columns: 2fr 1fr`, 높이 126px, 간격 2px. `PostRecord.thumbnailUrl` 을 쓴다. **이미 있는 값인데 화면에서 한 장도 안 쓰고 있다.** 이게 이번 작업에서 제일 큰 변화다
- 썸네일이 3장 미만이면 있는 만큼만 채우고 나머지는 `--line` 색 빈 칸으로 둔다
- 설명: `summary` 의 첫 문장을 쓴다. 없으면 `why_now`. 둘 다 없으면 칸을 비우되 `min-height` 는 유지해 카드 높이를 맞춘다
- 태그: 출신 + 눈에 띄는 것 하나. 세 개를 넘기지 말 것
- 카드 모서리 13px, 격자 간격 12px

### 선택 상태

카드를 누르면 담긴다.

- 배경 `--sel`, 테두리 `--selbd`
- 좌상단 19px 체크박스. 선택 전에는 반투명 흰 사각형, 선택 후에는 `--blue` 에 흰 체크
- 선택된 카드 안의 태그 알약은 배경을 흰색으로 (연보라 위에 회색이 묻힌다)

## 4. 하단 담기 바

`position: fixed`, 화면 하단. `body` 에 `padding-bottom: 88px`.

```
[썸네일 26px 2개]  2건 담음          [참조 이미지 팩] [색 팔레트] [카드뉴스로 넘기기]
```

- "2건" 만 `--blue`
- 주 버튼(카드뉴스로 넘기기)만 그라데이션
- 0건이면 바를 숨긴다

### 세 버튼이 하는 일

| 버튼 | 지금 되나 | 내용 |
|---|---|---|
| 참조 이미지 팩 | 된다 | 담은 후보들의 썸네일을 묶어 내려받기 |
| 색 팔레트 | **이번에 만든다** | 썸네일에서 주요 색 4개 추출. API 호출 없음 |
| 카드뉴스로 넘기기 | 된다 | 계약 JSON 을 담은 후보만으로 뽑는다 |

색 팔레트는 이미지를 읽어 색을 세는 코드다. 라이브러리 없이 canvas 로 픽셀을 훑으면 된다. 카드뉴스 담당자가 템플릿 색으로 쓴다.

## 5. 회차 자동 실행

지금은 사람이 버튼을 눌러야 회차가 돈다. 자동으로 돌게 한다.

### 방식

앱 안에 스케줄러를 넣지 말 것. 서버가 떠 있어야 하고 재배포하면 초기화된다. 밖에서 `POST /api/discover` 를 부르는 쪽이 맞다.

```
지금(로컬)   윈도우 작업 스케줄러 → curl 로 POST        무료
배포 후      cron-job.org 같은 외부 크론이 배포 URL 호출   무료
```

로컬용 배치 파일 하나와 등록 방법을 `docs/` 에 적어줄 것. 배포 후 방식은 그때 정한다.

### 비용 상한을 반드시 넣을 것

회차당 약 $1.5~2 다. 매일 돌리면 월 $45~60 이고, 자는 사이에 나간다.

- 기본값은 **주 3회** (월·수·금 오전 8시)
- 하루 최대 회차 수를 코드에 상수로 박는다. 넘으면 요청을 거부한다
- 자동으로 돈 회차는 `runs` 에 그렇게 표시한다. 사람이 누른 것과 구분이 돼야 한다

### 화면

설정 페이지에 요일·시각·켜기/끄기. 목록 맨 위 상태 줄이 그 값을 읽어 보여준다.

## 6. 하지 말 것

- 가로 한 줄 배치 (시도했고 정보가 많아 보였다)
- 카드 안 스파크라인 (26px 안에 일곱 개를 그리면 깨져 보인다. "9월에 두 배" 같은 태그로 대신한다)
- 4칸 이상 격자
- 그라데이션을 네 군데 넘게 쓰는 것
- 판정 로직·수집·계약 JSON 수정
- 밈/이슈 페이지를 같이 고치는 것 — 캐릭터가 확정되면 같은 틀을 옮긴다

## 7. 순서

```
1  토큰 + 글꼴 교체              (색·폰트만. 배치 그대로)
2  카드 구조 + 썸네일            ← 제일 큰 변화
3  오늘 들어온 것 / 전체 구분
4  선택 + 하단 담기 바
5  색 팔레트 추출
6  회차 자동 실행
```

1·2 를 하고 한 번 보여줄 것. 방향이 맞는지 확인하고 3부터 간다.
