### T4 방식 제안 (사용자 승인 대기)

지시서는 A 우선이지만, A는 오늘 돌려도 점이 하나라 선이 안 그려진다. 그래서 순서를 바꿔 제안했다.

```
D(유튜브 소급 8주) + 이름 대조 필터  → 오늘 선이 그려짐. 점선으로 표시
A(틱톡 게시물 재조회)               → 내일부터 실측. 실선으로 표시
못 잰 후보는 "유튜브로는 못 쟀음"으로 두고 회차를 기다린다
```

유튜브 실측(8주 창·`order: relevance`·50건 상한, 2026-09-15):

```
김승원    0·0·0·0·0·0·0·50   급등 (가장 이른 영상 9/11 — 진짜 신규)
쿠키런    5·1·1·2·4·4·7·26   상시 + 최근 상승
치이카와   4·2·10·8·4·9·9·4   평탄
빵고미    13·7·6·6·4·3·5·3   하강
지제왕 제바 0·0·0·0·0·0·2·0   2건 — 자가 안 닿음
```

**함정 둘.**
1. `order: 'date'` 로 바꾸면 최신 50건만 와서 전부 마지막 주로 쏠린다. `relevance` 를 유지할 것.
2. 검색이 이름을 느슨하게 맞춘다. `컬러스틱맨`·`춘람` 같은 신인이 50건 꽉 찬 건 관계없는 영상이 걸린 것이다.
   → 레이더 `spread.require_text_match` 와 같은 규칙을 걸 것: **제목·설명에 이름이 실제로 있는 것만** 남기고,
   남은 게 4건 미만이면 기울기를 만들지 않는다. 추가 호출 없음(이미 받아 온 영상의 제목을 보는 것).

**유튜브의 역할은 '발굴 소스'가 아니라 '자(尺)'다.** 후보는 틱톡·인스타·X·뉴스가 낳고,
유튜브에는 "이 이름 8주간 어땠나"만 묻는다. 유튜브 인기 목록은 2026-09-15에 후보에서 내렸다
(영상 제목은 트렌드 이름이 아님 — 레이더 `terms_are_titles`).
유튜브 자는 「한창·식는 중」에 잘 듣고 **「지금 선점」에는 약하다** — 그 칸은 회차 누적이 채운다.

## T1~T5 (원문)

**T1 게시물 테이블 분리** — `post_id · url · posted_at · account · views · candidate_id · round_no`.

`ownership: corporate` → "기업 IP · 소재 사용 가능" 류. 권리는 차단 조건이 아니라 참고 표시.
완료 조건: corporate 후보에도 카드뉴스가 생성된다.

**T4 시간 변화** — 위 제안 참조. 추정 구간과 실측 구간을 점선/실선으로 구분.
