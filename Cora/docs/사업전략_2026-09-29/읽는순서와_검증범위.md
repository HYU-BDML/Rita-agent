# 읽는 순서와 검증 범위

2026-09-29

**개인 고객과 계정 분석에 관한 최신 보완:** [개인 계정 성장지원과 콘텐츠 추천 설계](개인계정_성장지원과_콘텐츠추천_설계.md). 계정을 처음 시작하는 사람과 운영 중인 사람의 경로, Instagram 지표의 조건, 소재·영상 제작 연결, 대행사와 공유할 제품 구조를 정리했다. 대행사만을 위한 납품 도구로 제품을 한정하지 않는다.

**최신 BM·가격·실행 계획은 [BM 의사결정 화면](BM_의사결정.html)과 [BM 평가와 구체 실행 계획](BM_평가와_구체실행계획.md)을 먼저 본다.** 월 59,000원 단일 브랜드·149,000원 대행사 기본, 단위경제성·획득비·8주 예산과 담당자를 연결했다. 기존 5만원 시험 상품은 초기 탐색안이며 이번 가격 제안으로 대체한다. 이전 문서의 39만원 구독 계산은 산술 예시로만 남는다.

1. **전략검토.html**: 핵심 판단, 경쟁 전략, 인력·예산·사업 계산기, 전체 문서 열람.
2. **경쟁에서_이기는_진입전략.md**: 경쟁사별 승리 조건, 작은 개선의 누적 가치, 가격 인하·기능 복제 대응, 진입과 확대 방법.
3. **사업판정과_제품방향.md**: 경쟁·고객·가치제안·진입장벽·경제성·크리에이터·Rita에 관한 종합 판단.
4. **실행인력과_8주검증계획.md**: 필요한 사람의 역할과 최소안·확장안, 추가 실비 30만원의 범위, 서비스 수요와 SaaS 수요의 분리.
5. **프로젝트헌법_제안.md**: 개발·사업 판단에 적용할 17개 원칙. 경쟁 기능이 존재한다는 이유로 진입을 포기하지 않는다는 사용자 지시 반영.
6. **해외기업_근거와해석.md**, **한국시장_경쟁과기회.md**, **Rita_자산과연결판단.md**: 각 판단의 상세 근거.

2026-09-29 경쟁 전략 수정: 기존 보고서의 ‘독점적 기능 차별화 미통과’ 판정을 철회하고 ‘선택 고객의 실제 업무에서 종합 가치 우위: 비교 미실시’로 바꿨다. 현재 인력으로 전 기능 동시 개발이 어렵다는 점과 시장의 진입 가능성을 구분했다. 시간 30% 절감은 특정 실험의 목표일 수 있으나, 모든 상품의 필수조건으로 사용하지 않는다.

## 확인한 것

- 해외 7개 기업의 공식 실적·제품·거래·전환 자료. Manychat·Planable은 별도 비교 근거로 검토.
- 국내 대안과 해외 서비스의 한국어·브랜드·승인·에이전트 연결 기능.
- 사용자가 지정한 Rita 폴더의 기획·회의·인계 문서와 관련 트렌드·렌더 코드.
- 실제 인력 조건에 맞춘 시나리오. 1인당 주 4~5시간이라는 해석을 명시.
- 독립 비판 검토 후 서비스 결제와 SaaS 결제, 고객/제작팀 노동, 최소 인력안, 실제 총예산을 분리해 수정.
- 경쟁 전략을 별도 비판 검토하고 첫 승리 가설, 필요한 승인 자료, 실제 편집 환경으로의 전달 조건을 구체화.

## 아직 확인하지 못한 것

- 한국 대상 고객의 실제 작업 관찰·가격 수용·유료 주문·갱신.
- 경쟁 제품과 우리 결과물의 실제 품질·시간 비교.
- Rita 현행 본체 코드와 현재 상업 결제·성과 회수의 작동 상태.
- SNS 계정 연결·발행·지표 수집의 실제 실행 성공.
- 전업 운영비·디자인 외주 견적·학생 보수·실제 고객 획득비.

숫자와 가격 중 ‘제안·가정·상한’으로 표시한 것은 시장 조사로 확인된 값이 아니다. 사업 계산기는 가정을 바꿔 보는 계산 도구이며 매출 예측이나 성공 확률 계산기가 아니다. 원본 프로젝트·계정·운영 서비스는 변경하지 않았고, 고객 모집 메시지·구매·광고 집행도 하지 않았다.

## 산출물 점검

HTML 내부 문서 링크와 JavaScript 문법을 확인했고, 지원 1시간/6시간 시나리오의 계산을 별도로 대조했다. 브라우저 자동 검수 도구가 초기화 오류를 반환하여 실제 화면 렌더링·클릭 검수는 수행하지 못했다. 파일 열기를 앱에 요청했으나 응답은 queued였으므로 열린 상태를 확인했다고 말하지 않는다.

BM 계산기는 59,000원·149,000원 상품의 세 원가 시나리오, 획득·설정비 회수, 고객 가치, 고정비 충당 고객 수를 별도로 계산했다. 최신 보고서는 과금·사업성, 고객 확보, 구현 용량을 나눠 검토하고 피드백을 반영했다. 실제 고객 데이터로 검증한 수익성은 아니다.
