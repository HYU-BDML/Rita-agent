# Cora 실행과 인계 검증 결과

2026-09-29. 로컬 개발 버전과 인계 문서의 검증이다. 외부 고객 대상 운영 안정성·시장 수요·성장 효과의 검증은 아니다.

## 이번에 실제 추가한 기능

| 기능 | 동작 | 증거 |
|---|---|---|
| 브랜드 설정 | 이름·대상·목표·색상·메모를 사용자별 DB에 저장하고 새 제작에 적용 | operations-proof.json |
| 제작 상태·메모 | 작성 중/검토 필요/내 검토 완료, 검토 메모 보관 | 같은 파일 |
| 검토 무효화 | 검토 완료본의 문구·카드·브랜드가 바뀌면 서버 저장 시 작성 중으로 복귀 | 같은 파일 + 단위 시험 |
| 보관함 필터 | 브랜드·상태별 작업 선택 | 같은 파일 |
| 사본 제작 | 현재 콘텐츠를 새 ID로 저장, 원래 저장본 유지 | 같은 파일 |
| JSON 복원 | 입력 검증 후 새 초안으로 복원, 원래 소유권·게시 URL·검토 완료 상태 미승계 | 같은 파일 + 단위 시험 |
| 작업 삭제 | 본인 소유권과 현재 버전 확인, 해당 프로젝트/저장 이력 삭제 | 같은 파일 + 단위 시험 |

브랜드 메모는 보관용이며 아직 모델 규칙으로 자동 적용하지 않는다. 저장한 브랜드는 현재 새 항목 추가 방식이며 편집·삭제 화면은 후속 개선이다. 작업 상태는 개인 정리용이며 고객 승인·게시 상태가 아니다. JSON 복원은 ZIP 안의 project.json 또는 JSON 백업을 사용한다. 이미지 생성·영상 생성·공식 계정 분석을 연결했다고 표시하지 않는다.

## 실제 시험

- 프로덕션 빌드 통과.
- 단위 시험 328개: 327 통과, 실패 0, 기존 관측 DB 의존 시험 1개 명시적 제외. 원본 DB는 GitHub 이관에서 제외되어 해당 통합 시험은 미검증이다.
- 기본 Chrome 회귀 시험: 가입·사진/문구/순서 편집·저장·새로고침·다시 열기·PNG ZIP·버전 충돌·계정 분리·외부 Origin 차단·로그아웃/재로그인·390px 화면 통과. `증거/proof.json`.
- 운영 기능 Chrome 시험: 브랜드 재사용·검토 상태 무효화·메모/필터·사본·삭제·JSON 복원·카드 추가/삭제·타인 브랜드/삭제 접근 차단 통과. `증거/operations-proof.json`.
- 시험 중 브라우저 pageerror 없음. 증거 이미지는 가상 계정과 가상 책방 자료다.
- ZIP CRC, PNG의 1080×1350 크기, 편집한 문구와 순서는 별도 산출물 검사로 확인했다. 결과는 `증거/artifact-checks.json`.
- 로드맵 HTML의 렌더·검색·원가 계산·상대 파일 연결 검사는 통과했으며 `증거/document-proof.json`에 기록했다.

## 연구·소스 점검

기존 마스터플랜·15편 문헌 요약·32개 벤치마크·Mirr 분석을 읽고 현재 로드맵으로 통합했다. 이전 문헌 전문을 이번에 모두 다시 읽었다는 뜻은 아니다. 세부 접근 범위는 부록 문헌 문서를 따른다.

이번에는 Planable 승인/고객 작업공간, ContentStudio 승인, Buffer 기능/가격/공개 지표, Metricool 가격, Mirr 공개 페이지, 미리캔버스, Sabrina 원문을 재확인했다. Planable·ContentStudio·Mirr·Buffer 공개 소개 화면을 캡처했다. 로그인 후 내부 제품을 모두 직접 시험하지 않았고 경쟁사 대비 우월성을 실증하지 않았다.

Sabrina의 예전 Blotato 템플릿/API 링크는 이동되어 최신 Markdown 문서를 직접 가져와 읽었다. 출처: https://help.blotato.com/integrations-and-automation-templates/templates/5-automate-instagram-carousels-with-ai-chat.md 및 https://help.blotato.com/rest-api-reference/api-reference.md . 현재 문서는 계정 목록·게시 요청·게시 상태 조회를 구분한다. 공개 문서를 확인한 것이 실제 API 자격·요금·다고객 SaaS 사용 조건의 확인은 아니다. API 키를 발급하거나 유료 호출·게시를 실행하지 않았다.

GitHub main의 카드뉴스 경로는 확인 시 README만 있었다. 배포 앱 URL만으로 서버 소스 통합 완료를 선언하지 않는다. 기존 프로젝트 폴더는 변경하지 않고 Cora 하위만 수정한다.
