# Cora 인계 패키지

Cora는 여러 브랜드를 정기 운영하는 작은 팀의 콘텐츠 제작·수정·검토·게시·회고를 연결하려는 서비스다. 현재 실제 작업본은 카드 제작과 개인별 작업 관리까지 제공한다. AI 생성·고객 승인·실제 SNS 게시·Instagram 진단은 후속 단계다.

## 읽는 순서

| 순서 | 파일 | 무엇을 알 수 있는가 |
|---|---|---|
| 1 | 01_전체로드맵.html | 전체 그림, 단계별 계획, 사업 가정과 원가 계산 |
| 2 | 01_사업과제품_실행계획.md | STP·가치 제안·BM·벤치마크·MVP·12주·연구·출시 판단의 상세 근거 |
| 3 | 02_유경이_실행과검수.md | 설치·첫 4.5시간·사용 순서·문제 보고·작은 코드 개선 |
| 4 | 00_진행체크리스트.md, 04_검증결과.md | 이번 작업 완료표, 시험 증거, 아직 못 한 것 |
| 5 | 03_기능검수표.csv, 03_사용실험기록.csv | 학생의 검수와 실제 고객 업무 비교 기록 |
| 필요 시 | 부록/ | 기존 전체기능 명세·문헌·설계·32개 벤치마크 |

HTML은 다운로드 후 브라우저에서 열면 된다. 스크린샷은 공개 소개 화면과 우리 작업본을 구분해 표시했다. 공개 사이트 캡처는 로그인 후 내부 기능을 직접 검증한 증거가 아니다.

## 유경이에게 전달할 메시지 초안

> 유경아, Cora 첫 작업본과 전체 계획을 정리했어. 먼저 01_전체로드맵.html을 보고, 02_유경이_실행과검수.md에 따라 실행해 봐. 이번 주에는 실제 사용할 수 있는 자료 하나로 카드뉴스를 끝까지 만들고, 가장 크게 막힌 부분을 기록하면 돼. 코드를 처음부터 다 만드는 과제가 아니라, 이미 만든 것을 써 보고 개선하는 방식으로 진행할 거야. 4~5시간 안에서 할 일을 하나씩 정하자.

이 메시지는 초안이며 학생에게 발송하지 않았다.

## 역할과 완료 규칙

임보람은 고객·제품·연구·비용 판단을 맡고, 유경이는 주 4~5시간의 사용 시험·관찰 기록·작은 개선을 맡는다. AI는 구현·수정·시험·문서를 수행한다. 개발자는 실제 고객 공개 전에 확인된 위험을 독립 검토하고 보완한다. 구현→자가 검증→학생 사용→수정→재시험 순서로 진행한다. 학생 시험은 AI가 해야 할 기본 검증을 대신하는 일이 아니다.

개발 목표는 12주 동안 합의한 기능의 90% 이상을 사용자·학생·AI가 구현하는 것이다. 현재 완료율이나 성공 보장이 아니다. 기능 수·코드량보다 실제 작업 완료와 반복 사용을 확인한다.
