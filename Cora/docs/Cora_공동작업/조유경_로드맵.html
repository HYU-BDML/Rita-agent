Cora · 조유경 10주 로드맵 · 2026-10-05 ~ 12-13

Cora를 직접 쓰고, 고치고, 연결하는 10주

Cora(Content Operations Run by Agents)는 여러 브랜드의 SNS 콘텐츠를 만드는 작은 대행사가 자료 입력부터 제작·검토·게시 준비·성과 확인까지 한곳에서 처리하도록 돕는 서비스입니다. 유경이는 매주 4~5시간 동안 제품을 실제로 써 보며 시간과 수정 횟수를 기록하고, AI와 함께 작은 기능과 무료 API 연결을 직접 만듭니다.

먼저 기억할 세 가지
① 실제 SNS 계정에 올리는 게시는 교수님이 준비한 시험 계정에서만, 교수님 확인 뒤에 합니다. ② 비밀번호·API 키·고객 자료는 채팅·문서·Git에 올리지 않습니다. ③ 막히면 30분 안에 대체 과제로 넘어가고 주간 보고에 적습니다.

지금 Cora에서 되는 것과 안 되는 것

원장 119개 기능 가운데 2026-09-30 기준 브라우저 검증됨 4개, 부분 검증 73개, 부분 구현 22개, 미구현 20개입니다. 남은 20개는 모두 외부 API가 있어야 하는 기능입니다. “부분”은 핵심 흐름은 동작하지만 일부 옵션이나 실제 외부 연결이 남았다는 뜻입니다.

실제 SNS 게시 시험은 교수님이 시험 계정을 주고 AI가 Instagram 연결을 끝낸 주부터, 그 주의 코드 과제 대신 진행합니다.

처음 한 번 하는 준비

  1. Node.js 22.13 이상과 Git을 설치하고, 터미널에서 node --version이 v22.13 이상인지 확인합니다.
  2. Drive 동기화 폴더가 아닌 일반 폴더에서 코드를 내려받습니다. GitHub 계정은 필요 없습니다.
git clone --branch cora/project-bootstrap https://github.com/HYU-BDML/Rita-agent.git
cd Rita-agent/Cora/apps/trend-hub
node scripts/run-local.mjs
  1. 브라우저에서 http://127.0.0.1:3210/studio를 열고 시험 계정 두 개(제작자·검토자)를 만듭니다. 비밀번호는 10자 이상, 다른 곳에서 쓰지 않는 것으로 합니다.
  2. 본인이 발급한 무료 키는 본인 컴퓨터의 ~/.config/cora/secrets.env에 이름=값으로 적고, chmod 600 ~/.config/cora/secrets.env로 본인만 읽게 합니다.
  3. 매주 작업을 시작할 때 git pull로 교수님 저장소의 최신 코드를 받습니다.

첫 3주 과제

매주 “제품 사용(약 2시간)”과 “무료 API 연결(약 2.5시간)”을 함께 합니다. 기록은 Drive outputs/조유경_10주/W01~W03 폴더에, 코드 수정은 패치 파일로 outputs/조유경_10주/패치/에 올립니다.

1주차 · 전체 흐름 1회와 YouTube 정보 가져오기 검증

제품 사용 (2시간)

  1. “예시로 먼저 해보기” → “소재 방향 살펴보기” → 방향 1개 선택으로 카드를 만들고, 문구 2곳·사진 1곳을 바꿔 “작업 저장”합니다.
  2. “다른 사람에게 이 버전 검토 요청”에 두 번째 계정 이메일을 넣고, 두 번째 계정의 “검토함”에서 승인합니다.
  3. “게시 준비함”에서 승인본으로 게시 준비 → “모의 큐 등록” → “자동 진행 예약” → “실행 시각이 된 예약 지금 실행”을 두 번(10초 간격) 눌러 “모의 완료 (실제 게시 아님)”까지 확인합니다.

무료 API 연결 (2.5시간)

  1. Google Cloud 콘솔에서 새 프로젝트 → YouTube Data API v3 사용 설정 → API 키를 만듭니다(카드 등록 불필요). 하루 10,000단위, 영상 정보 1건은 1단위입니다.
  2. ~/.config/cora/secrets.env에 YOUTUBE_API_KEY=발급값을 넣고 Cora를 다시 실행합니다.
  3. “PDF·YouTube 가져오기”에 공개 한국어 영상 주소 5개(일반 주소, youtu.be 짧은 주소, 쇼츠, 재생목록이 붙은 주소, 삭제된 영상)를 넣고 제목·설명·길이·오류 문구를 표로 기록합니다.
  4. 기대와 다른 결과 1건을 골라 아래 AI 요청 양식으로 고치고 패치 파일을 올립니다.

완료 판정: 모의 완료 화면 캡처 1장, 영상 5건 모두 결과 또는 이유가 적힌 오류 표시, 패치 1건. 막히면: 설치 오류 전문(키 제거)을 버그 보고로 남기고, 교수님 컴퓨터에서 흐름만 진행합니다.

2주차 · 브랜드 3개 제작 시간 측정과 웹 검색 연결

제품 사용 (2시간)

  1. 가상 대행사 브랜드 3개(예시 “모퉁이 책방”, 공공기관 보도자료 1곳, 학과·동아리 공지 1곳)의 이름·대상·목표·색상·말투 메모를 저장합니다.
  2. 브랜드마다 카드뉴스 1건(4~6장)을 만들고, 자료 입력부터 PNG 다운로드까지 걸린 분, 고친 카드 수, 원문에 없는 사실 수를 사용실험기록에 적습니다.

무료 API 연결 (2.5시간)

  1. tavily.com에서 무료 키를 발급합니다(월 1,000크레딧, 카드 불필요). CORA_TAVILY_API_KEY=발급값으로 넣습니다.
  2. AI에게 lib/cora/search/tavily.ts 어댑터를 만들게 합니다. 기존 lib/cora/publishing/instagram.ts처럼 가짜 응답으로 먼저 시험하고, 결과마다 출처 URL과 검색 시각을 저장해야 합니다.
  3. “소재 탐색” 탭에 “웹 검색” 결과를 표시하고, 브랜드 3개의 주제로 검색 3회를 해서 RSS 결과와 무엇이 다른지 표로 비교합니다.

완료 판정: 사용실험기록 3행의 숫자가 모두 채워짐, 가짜 응답 시험과 실제 검색 모두 통과, 패치 1건. 막히면: 어댑터와 시험까지만 패치로 올리고, 화면 연결은 다음 주로 넘깁니다.

3주차 · 블로그 개요 승인 흐름과 자막 자동 생성

제품 사용 (2시간)

  1. “AI 글·대본” 탭의 “개요 먼저 승인하고 본문 쓰기”로 블로그 2건을 만듭니다. 개요를 한 곳 이상 고친 뒤 승인하고, 본문에 고친 내용이 반영됐는지 확인합니다.
  2. 검토·승인·게시 준비까지 진행하면서 기대와 다른 동작 3건을 버그 보고 양식으로 적습니다(“3회 중 몇 회 발생” 포함).

무료 도구 연결 (2.5시간)

  1. whisper.cpp를 설치하고 한국어 모델을 내려받습니다(키·사용료 없음).
  2. 본인이 찍은 30초~1분 한국어 영상 2개로 SRT 자막을 만들고, 틀린 어절 수 ÷ 전체 어절 수로 정확도를 적습니다.
  3. 만든 SRT와 영상을 Cora의 “긴 영상 → 숏츠” 화면에 올리고, 목적을 하나 골라 “규칙으로 추천(AI 없음)”과 “AI로 구간 추천”의 결과를 비교합니다. 더 나은 구간 1개를 배경음악과 함께 세로 숏츠로 만들고, 두 추천이 어떻게 달랐는지 세 줄로 적습니다.

완료 판정: 버그 보고 3건, SRT 2개와 정확도 표, 설치 절차 메모. 선택 과제: Gemini 무료 키로 공개 카드뉴스 이미지 5장의 색·배치 규칙 분석(고객 이미지는 넣지 않음, 이미지 입력 지원 여부 먼저 확인).

코드 수정을 보내는 방법

  1. 작업 전 git pull, 수정 후 화면에서 직접 확인합니다.
  2. Cora 폴더에서 git diff > W01_주제.patch로 패치 파일을 만듭니다.
  3. 패치 파일과 “무엇을 왜 바꿨고 무엇을 확인했는가” 세 줄을 outputs/조유경_10주/패치/에 올립니다.
  4. AI가 적용·시험해 교수님 저장소에 반영하면 git checkout . 후 git pull로 반영본을 받습니다.

처음에는 화면 문구·안내 문장·빈 상태 표시·무료 API 어댑터를 직접 고칩니다. 3주차까지 패치 2건이 시험과 함께 반영되면 입력 검증·필터·작은 기능으로 범위를 넓힙니다. 로그인·결제·실제 게시·DB 구조 변경은 교수님·AI가 맡습니다.
