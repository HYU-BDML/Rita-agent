# 유경의 2시간 첫 사용 워크북

**시작 파일: `00_유경_2시간_워크북.html`**. 별도 설치 없이 브라우저에서 안내·피드백을 사용할 수 있는 파일이다. 실제 콘텐츠 제작을 하려면 Cora 서버는 별도로 실행해야 한다.

학생에게는 Drive outputs의 **`Cora_유경_2시간_전달.zip`** 하나를 전달한다. 풀면 HTML·전달 안내·기존 검증된 소스 ZIP이 함께 나온다. Drive 미리보기 대신 내려받은 HTML을 Chrome/Edge에서 연다. Git 원본에는 키나 소스 ZIP을 중복 커밋하지 않는다.

| 시간 | 할 일 | 남길 것 |
|---|---|---|
| 0–20분 | 실행·시험 계정·제품 이해 | 환경, 실행 결과 또는 오류 |
| 20–35분 | 가상 고객사 A/B 규칙 저장 | 구분·저장 결과 |
| 35–60분 | A 자료 → 후보5 → 선택3 → 주간 계획 저장 | 후보 평가·선택 이유 |
| 60–85분 | 카드 한 묶음·캡션 편집·저장·내보내기 | 수정 전/후, PNG ZIP·작업 JSON |
| 85–105분 | 재접속·A/B 전환·다음 주 복제·이동 경고 | 검사 결과. 카드 복구·검토 상태는 시간 남으면 |
| 105–120분 | 큰 문제 최대3건·개선1개·제출 | 피드백 JSON·읽기용 보고서·캡처 |

모든 검사 기본값은 **미실행**이다. 설치가20분 이상 막히면 실행 오류만 기록해 제출한다. 팀 초대·실제 AI·광고·SNS 연결/게시·시장 수요 검증은 이 과제에 포함하지 않았다. 제품 코드 기준은 **b7d2a95**이며 전체119개나 출시를 완료했다는 뜻이 아니다.

응답은 브라우저 localStorage에 임시 저장된다. HTML/Drive에 응답이 자동 기록되지 않으며 전송·알림도 없다. 저장 차단·브라우저 변경·파일 경로 변경에 대비해 **중간 JSON 백업**을 권한다. 다른 컴퓨터에서는 제출 단계의 ‘피드백 JSON 가져오기’로 복원한다. 교수님도 같은 방법으로 제출 요약을 볼 수 있다.

피드백 JSON과 Cora 작업 JSON은 별개다. 마지막에 학생이 내려받은 파일과 PNG ZIP·캡처를 권한 있는 공유 Drive의 `outputs/조유경_10주/제출/시험일_조유경_첫사용/`에 직접 넣는다. 학생 응답/결과물은 Git 버전 관리 대상이 아니다.

## 유지·검수

`test_workbook.mjs`는 합성 입력으로 워크북만 검수한다. `CORA_PLAYWRIGHT_MODULE`로 설치된 Playwright 모듈 위치를 지정하고 `node test_workbook.mjs`를 실행한다. 기본 결과 경로는 `/tmp/cora-workbook-proof`이며 환경 변수 `CORA_WORKBOOK_TEST_DIR`로 바꿀 수 있다. 실제 학생 시험이나 Cora 제품 검수를 대신하지 않는다.

검수 증거·한계는 `02_워크북_검증.md`, `workbook-proof.json`을 따른다. 기존 2026-10-04 학생 자료·소스 ZIP은 보존하며 최신 첫 사용 진입은 이 HTML로 통일한다. 제품 기능과 원본119개 원장은 변경하지 않는다.
