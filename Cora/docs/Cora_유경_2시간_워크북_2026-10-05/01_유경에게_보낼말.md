# 유경에게 그대로 전달할 메시지

유경아, Cora 첫 사용을 2시간만 해 보자. 여러 고객사의 SNS 콘텐츠를 만드는 사람이 고객사 규칙과 자료를 정리하고, 이번 주 제작할 콘텐츠를 고르고, 카드·캡션을 만들어 저장하는 과정을 시험하려는 거야.

같이 보낸 `Cora_유경_2시간_전달.zip`을 일반 폴더에 풀고 **`00_유경_2시간_워크북.html`을 Chrome 또는 Edge로 열어 줘.** Drive 미리보기에서 버튼이 안 되면 먼저 다운로드한 파일을 열면 돼. 워크북의 1번부터 순서대로 하고 피드백을 바로 입력해 줘. 실제 Cora 앱은 안내에 따라 별도 탭에서 열어야 해.

이번 과제는 가상 고객사 A/B를 만들고, A의 자료로 이번 주 후보 3개를 고른 뒤 **카드 한 묶음만** 편집·저장·내보내는 거야. 이후 저장·고객사 전환·다음 주 복제를 확인해 줘. 처음 10분은 직접 찾아보고, 이후 도움받은 내용과 시간을 따로 적으면 돼. AI·광고·Instagram 연결·게시는 이번에 하지 않아.

실행 준비가 20분 넘게 막히면 계속 설치하지 말고, 오류와 시도한 방법을 적어서 제출해 줘. 하지 못한 검사는 ‘미실행’으로 두면 돼. 잘 된다고 답할 필요 없이, 실제로 어디서 막히고 얼마나 고쳐야 쓸 만한 결과가 됐는지 알고 싶어.

마지막에 워크북의 **피드백 JSON + 읽기용 보고서**, Cora의 **카드 PNG ZIP + 작업 JSON**, 문제가 있으면 **화면 캡처**를 아래 공유 폴더의 `시험일_조유경_첫사용` 폴더에 넣어 줘.

`조유경(소셜미디어)/outputs/조유경_10주/제출/`

워크북의 임시 저장은 교수님에게 전송되는 게 아니니, 파일을 내려받아 직접 올려 줘. 제출 후 ‘끝냈어요/실행 막혔어요 + 제출 폴더 + 가장 큰 문제 한 줄’을 알려 줘. 첫 회는 사용과 피드백까지만 하고 코드 수정은 그다음에 같이 정하자.

## 교수님이 전달 전에 확인할 것

- 전달 ZIP을 첨부하고 공유 Drive 제출 폴더 접근 권한을 확인한다. 폴더 권한이 없으면 다운로드 파일을 먼저 받아도 된다.
- 교수님 PC에서 함께 시험할 때는 AI와 **별도 시험 데이터 경로**의 Cora 서버를 준비한다. 현재 주소만으로 열리는 공개 배포본은 없다.
- 학생 PC에서는 Node 22.13 이상과 패키지 설치용 인터넷이 필요하다. 학생 OS에서의 실제 설치 성공은 아직 검증하지 않았다. `127.0.0.1`은 해당 PC의 주소이며 원격 공유 주소가 아니다.
- 개인 키·운영 DB를 학생에게 전달하지 않는다. 첫 회의 원문 기반 제작에는 API 키가 필요 없다. 교수님 PC의 기존 LLM 환경에서 AI 버튼을 누르지 않도록 한다.
- 제출물을 받으면 이 워크북의 마지막 단계에서 **피드백 JSON**을 불러와 읽는다. Cora의 작업 JSON과 구분한다. 미실행을 자동 시험 결과로 채우지 않는다.
- 학생이 만든 DB/.env/다운로드 결과는 Git에 커밋하지 않는다. 구체적인 재현 증거를 검토하고 다음 구현 우선순위를 바꿀 수 있다.
