제품을 추가 개발한 기록이 아니라, 유경이에게 전달할 **독립 HTML 안내·피드백 도구**의 검증이다. 제품 코드 b7d2a95, 기존 첫 사용 소스 ZIP SHA256 `78ca06b9dddf6230bf7ef06319685b4e53ae932797b4b2c8fa458622c1c7fc51`를 기준으로 한다. 실제 UI의 ‘새 고객사’, ‘주간 콘텐츠 묶음’, ‘카드 초안 만들고 편집’ 명칭을 소스와 대조했다.

## 실제 수행

Playwright Chromium에서 **오프라인 file:// HTML, 합성 시험자 입력으로 26개 검사 통과**. 자세한 검사명과 시각은 `workbook-proof.json`, 재현 스크립트는 `test_workbook.mjs`에 있다.

- 7개 단계·120분 합계·12개 미실행 검사 기본값·단계 이동/메모·타이머 시작/정지/재열기.
- 입력 → 브라우저 임시 저장 → 새로고침 복원. 저장 차단 시 안내와 JSON 내려받기. 손상된 임시 JSON은 시작/종료만으로 덮어쓰지 않음.
- 피드백 JSON·읽기용 Markdown·선택 CSV 다운로드. Unicode·줄바꿈 보존, CSV 수식 시작값 보호.
- 다른 브라우저 컨텍스트에서 JSON 불러오기, 교체 취소, 초기화 취소/확인.
- 잘못된 제품 JSON·문법·버전·선택값·초과 길이·2 MB 초과 파일 거부. 스크립트처럼 보이는 가져온 문구는 문자로 표시하고 알 수 없는 키는 버림.
- 판정이 있지만 실제 결과가 빈 검사를 제출 요약에서 안내. 미실행을 통과로 자동 변경하지 않음.
- 1280px 데스크톱 및 390px 모바일 시각 확인·모든 단계 가로 넘침 없음·키보드 포커스. 모바일 단계 이동은 해당 내용부터 보여 줌.
- 페이지 실행 오류0, 외부 HTTP 요청0, 실제 AI/SNS 호출0.

전달 ZIP은 워크북·전달 안내·README·검증 기록·소스 ZIP·목록만 포함한다. 내부 파일 목록/해시와 ZIP 무결성을 확인하고, 원래 소스 ZIP의 해시를 대조한다. 키·DB·의존성 폴더·실제 학생 응답은 포함하지 않는다. 추가로 전달 묶음을 /tmp에 풀어 새 Chromium 컨텍스트에서 HTML을 열었고, 검사 판정0/12와 동봉한 소스 ZIP의 실제 다운로드·동일 SHA256을 확인했다. Cora119개 기능 원장·제품 코드는 변경하지 않았다.

## 범위와 사용상 한계

- **유경이의 실제 시험은 아직 미실행.** 합성 브라우저 검사26개는 학생 판정12개를 대신하지 않는다.
- Cora 서버를 시작하거나 앱 전체 검수를 다시 실행하지 않았다. 학생의 Mac/Windows 설치·제작 성공·결과 품질·팀 역할·AI·Instagram·실제 게시·독립 코드 리뷰·출시 준비를 완료했다는 의미가 아니다.
- 워크북만 서버 없이 열린다. 실제 Cora 제작은 안내의 별도 서버 실행이 필요하다. Node22.13+·첫 패키지 설치용 인터넷·서버 준비는 학생/교수 환경에서 확인한다.
- Chrome/Edge로 다운로드한 HTML을 여는 것을 안내한다. Safari·Drive 미리보기·모든 모바일 브라우저는 실검수하지 않았다. 모바일은 기록용, 제작 과제는 PC다.
- localStorage는 브라우저 임시 보관이며 기기/브라우저/파일 경로마다 달라질 수 있다. 응답이 Drive HTML에 자동 저장되거나 서버·교수에게 전송되지 않는다. JSON 내려받기·직접 제출·불러오기가 이식 경로다.
- 캡처/PNG ZIP/Cora 작업 JSON은 별도 제출한다. 이미지 파일을 HTML 임시 저장에 넣지 않는다. 공유 Drive 제출 폴더를 만드는 것은 실제 공유 권한 부여가 아니므로 교수님이 권한을 확인한다.
- 단계 타이머는 경과 시간이며 능동 편집 시간·도움 시간·대기 시간을 분리한 효율 평가가 아니다. 학생이 실제 시간을 별도로 기록하며 기억나지 않으면 비운다.

교수님은 학생 JSON을 워크북 마지막 단계에서 불러온 뒤 재현성이 큰 문제3개를 확인하고 다음 작업 우선순위를 조정한다. 학생의 첫 사용을 대행사 고객의 수요·지불의사 검증으로 해석하지 않는다.
