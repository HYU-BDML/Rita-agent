# Cora 근거 소재·주간 콘텐츠 묶음 검증 — 2026-10-04

검증 코드 **b7d2a95**. 지정 Drive checkout의 Cora에 구현했다. 고객사 자료를 후보5개로 구성하고 이번 주3개를 선정해 담당자·마감·카드 초안과 연결한다. 후보는 원문에서 만드는 **편집 방향**이다. 실시간 유행 탐지나 AI가 찾아낸 새로운 사실이라는 뜻은 아니다.

## 사용 흐름

1. 고객사를 선택하고 **이번 주 제작 → 주간 콘텐츠 묶음**을 연다. 최초 고객사 자료를 읽는 동안 입력 폼을 열지 않아 늦게 도착한 초기 응답이 입력을 덮어쓰지 않는다.
2. 자료 이름·원문·선택 출처 URL·확인한 게시일을 저장한다. 또는 공개 HTTPS URL 본문을 가져오거나, 해당 고객사에 저장한 소재를 새 근거 자료로 복사한다. 개인 자료·다른 고객사 자료는 자동으로 섞지 않는다. 저장한 원문은 수정하지 않는 사본이다.
3. 자료1~5개를 선택해 **자료로 후보5개 만들기**를 누른다. 소개/질문/체크 항목/조건 비교/다음 행동이라는 다섯 구성을 제안한다. 고객사 반복 주제가 원문에 문자 그대로 있는 경우만 일치 이유를 표시하며, 없으면 직접 적합성 확인이 필요하다고 안내한다. 각 후보에 출처·수집시간·사용자 입력 게시일·후보 생성 당시 경과일·규칙 버전·동일 원문/주소 표시를 보관한다. 자료가 하나면 같은 원문의 다른 구성이라고 표시한다.
4. 이번 주 후보를 최대3개 고르고, 목표·선택 이유·현재 편집 권한이 있는 담당자·그 주 안의 마감일을 저장한다. 월요일 주 시작일을 검사하며 미완성 계획도 저장할 수 있다. 카드 생성은3개 모두에 이유·담당·마감이 있어야 한다. 담당자 지정은 알림 발송이나 게시 예약이 아니다.
5. 저장된 계획에서 **카드 초안 만들고 편집**을 누른다. 기본4~6장·캡션을 저장하고 기존 편집기로 연다. 생성 시 최신 공통 브랜드 규칙을 붙이며 전체 원문·출처는 브리프에 보관한다. 카드/캡션은 최대1,200자 발췌로 구성하고 일부 발췌/미확인 사실을 검토 메모에 알린다. 사실성·디자인 적합성·광고 성과를 검증한 결과가 아니다.
6. 같은 후보 생성 버튼을 재요청하면 이미 연결된 카드 ID를 반환한다. 새 카드 저장·카드 버전·계획의 연결·계획 이력은 한 트랜잭션으로 처리한다. 연결 저장 실패 시 카드도 롤백한다. 다른 창이 계획을 먼저 바꿨으면409를 반환하고 해당 창의 입력을 보존한다.
7. 다음 주 계획으로 복제하면 목표·후보·선택 이유를 복사하고 마감일을 날짜 차이만큼 옮긴다. 카드 연결/승인은 복사하지 않으며 AI 호출도 없다. 이전 승인본은 그대로 유지한다. 최근 다른 계획에서 같은 원문을 선택했으면 겹침을 안내한다. 담당 권한이 회수됐으면 다시 지정한다.
8. 계획을 다시 열어 저장한 값과 수정 이력을 확인한다. 연결 카드의 최신 버전/내 작업 상태를 보여주되 고객 승인으로 해석하지 않는다. 카드가 삭제되거나 다른 고객사로 옮겨졌으면 내용 대신 연결을 찾을 수 없다고 표시하고 새 초안을 만들 수 있게 한다.

## 저장·권한·입력 계약

- 고객사 ID와 실제 소유자 workspace로 자료/후보/계획을 보관한다. 소유자와 해당 고객사의 초대를 수락한 현재 editor만 읽고 수정한다. reviewer·대기 초대·이름 기반 옛 grant·다른 고객사 ID·개인 자료는 이 경로에 접근할 수 없다. 담당자 목록도 이 고객사의 현재 편집자만 제공한다.
- URL를 읽는 네트워크 대기는 SQLite 트랜잭션 밖에서 한다. 응답 뒤 권한을 다시 확인하며 대기 중 회수되면 저장하지 않는다. 이전 고객사 요청이 늦게 도착해도 새 화면에 입력하거나 이전 카드를 다시 열지 않는다.
- 저장 필드: WeekPlan 목표/후보ID/선택3개/선택 이유/담당ID/마감/카드ID/version. 수정 때마다 immutable revision을 추가한다. 과거 이력의 선택과 연결을 조용히 최신 값으로 바꾸지 않는다. 파일 백업/반복 이전·계정 export/삭제에 주간 테이블을 포함한다.
- 직접 원문10~20,000자, 자료 이름200자, URL1,500자, 고객사당 자료100개·후보 묶음50개. 목표200자·선택 이유500자. 자료 목록100개/계획 목록 및 이력30개/기존 후보 중복 대조250개 한도다. 중복은 정규화된 원문의 해시 또는 정확히 같은 URL 비교이며 의미상 중복 탐지가 아니다. 다른 계획 중복 대조는 최근30개 계획이다.
- 공개 URL는 자격정보/비표준 포트 없는 HTTPS만 읽는다. DNS의 모든 IPv4 응답을 검사하고 검사한 주소로 연결한다. 내부망·예약/문서용 IP·비텍스트/큰 응답·본문 부족·과도한 redirect는 거부한다. 실패를 AI 창작으로 채우지 않는다. 추출 본문은 최대16,000자이며 잘림을 기록한다. HTML/직접 본문의 지시문은 실행하지 않고 React 텍스트로 표시한다.
- 게시일은 사용자가 확인해 입력한 값이다. 미입력/30일 초과/미래 날짜를 구분하고 최신 정보라고 인증하지 않는다. 수집일을 게시일로 대신 쓰지 않는다. 직접 입력한 URL은 참고 링크이며 본문과 실제로 일치하는지 인증하지 않는다.
- **주간 화면의 미저장 자료/계획은 아직 자동 복구함에 저장되지 않는다.** 이동·고객사 변경·로그아웃/새로고침 때 경고한다. 직접 자료 저장/주간 계획 저장을 해야 다시 열 수 있다. 기존 카드·일반 브리프 복구는 그대로 유지한다. 이 제한을 숨기지 않았다.
