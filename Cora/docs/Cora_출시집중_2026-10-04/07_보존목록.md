# 기능 보존과 첫 출시 차단

원본 위치는 `Cora/`에 유지한다. 이번 계획에서 소스를 물리적으로 이동하거나 API를 비활성화하지 않았다. 아래는 L03에서 구현할 분리 규칙이다. 숨긴 메뉴도 서버에서 실행 가능하면 출시 범위가 줄어든 것이 아니다.

| 묶음 | 기존 위치(Cora 기준) | 첫 출시 처리 | 다시 꺼낼 조건 |
|---|---|---|---|
| 긴 영상·AI 숏츠·음성·모션 | apps/trend-hub/lib/cora/video/; video.ts; 관련 app/api/cora/video* | 메뉴/API/백그라운드 렌더/업로드 차단. 카드 렌더가 공유하는 유틸은 유지 | 최소 2개 유료 고객의 반복 요청, 직접 촬영자료 확보, 렌더원가/품질 검수 |
| 블로그·SEO | lib/cora/blog-outline.ts 등 실제 모듈 목록은 rg로 재확인; workbench 글쓰기 경로 | 카드에 필요한 텍스트 생성과 공유 유틸 분리 후 블로그 action 차단 | 같은 고객의 운영 문제로 반복 확인될 때 |
| DM·댓글 자동 응답 | lib/cora/instagram*; 댓글·메시지 관련 route | 미사용 scope 요청 제거, 웹훅/자동응답 job 차단; 게시 어댑터는 유지 | 콘텐츠 제작/승인 가치가 먼저 확인되고 메시지 품질·권한 검증 |
| 다중 채널·Blotato | lib/cora/publishing/blotato.ts; ops/threads.ts | Instagram 공식 경로 외 실행 차단; 계약 fixture 보존 | 기존 고객이 채널 추가에 지불할 의사 + API 접근 검증 |
| 자연어 무인 반복 제작 | lib/cora/ops/recipes.ts; scheduler* | AI 레시피 자동 실행 차단; 승인본 예약 게시 scheduler는 재사용 | 운영 4주 오류·원가 기록 및 명시적 자동화 정책 |
| 경쟁 광고/인기게시물 대규모 검색 | 레거시 Trend 경로 및 E203 관련 수집 모듈 | 고객 메뉴/원본 DB 차단 유지; 허용 출처 소재 입력 재사용 | 이용 가능한 데이터 출처·비용·권리 검수와 고객 반복 수요 |
| 고급 편집·Figma·레이어 | 카드 편집 컴포넌트/모델·SVG export | 기본 편집은 유지, 고급 패널은 차단. 렌더가 읽는 레이어 자료를 지우지 않음 | 품질 결함을 해결하는 기능으로 필요성이 확인될 때 |
| 링크 페이지·추천 보상 | lib/cora/linkpage.ts; platform/referral.ts; /l/* | 공개 route/API/action/가입후 부작용 차단 | 핵심 유지율 확보 후 독립 매출/획득 실험 |
| 결제상점·연간요금·크레딧팩 | lib/cora/billing/ | 원가·한도 보존, 상품 변경/결제/추가구매 실행 차단 | 유료 파일럿 가격 확정 후 실제 결제 검수 |
| API·MCP·Rita | integrations/rita; lib/cora/platform/v1.ts; rita-contract.ts; scripts/cora-mcp.mjs | 내부 Rita 계약 시험 보존. /api/v1·api-docs·원격 MCP 고객모드 차단 | Rita에서 공통 계약으로 재사용; Cora 별도 공개 API는 고객 수요 후 |
| XGBoost·토픽모델·성장점수 | 기존 연구 설계 문서·향후 research 모듈 | 출시 의존성 제외. 현재 모델이 있는 것처럼 광고하지 않음 | 동의된 충분한 표본·계정/시간 분리·외부검증·단순기준선 우위 |

L03 실행 순서: (1) route/action/worker/import 역참조 목록 → (2) 출시 capability registry 설계 → (3) server-side deny 및 UI nav 연동 → (4) 직접 호출·환경값 누락 시험 → (5) 구버전 자료 열람/복원 시험 → (6) 기능을 쓰지 않는 배포 산출물과 dependencies 검증.

물리적 분리는 의존성이 없는 모듈에 한해 `Cora/labs/<기능>/`로 `git mv`한다. 보존 README에 원래 경로·마지막 커밋·시험·의존성·복귀 절차를 남긴다. import가 얽힌 모듈은 제자리에 두고 기능 차단한다. `apps/trend-hub/app` 안의 폴더 이름만 archive로 바꾸면 새 route가 되므로 보존 방식으로 쓰지 않는다. 사용자 DB·미디어는 이동/삭제하지 않는다. 모델/schema 이전은 L06을 먼저 통과한다.
