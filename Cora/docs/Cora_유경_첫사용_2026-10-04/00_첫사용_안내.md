# 유경이의 Cora 첫 사용 — 2026-10-04

대상 코드 b7d2a95(문서 기준5625fcf). 첫 회는 90~120분, 원문 자료 기반 제작만 시험한다. 학생에게 GitHub 계정·API 키·Instagram 로그인·배포 설정을 요구하지 않는다. 실제 생성 품질·시장 수요 검증은 이 시험 뒤 별도로 한다.

## 목표와 현재 상태

Cora는 여러 고객사의 SNS 콘텐츠를 만드는 작은 대행사·프리랜서 팀을 돕는다. 고객사 규칙과 근거 자료를 보관하고, 이번 주 만들 콘텐츠를 선택해 카드·캡션을 편집·저장하며, 이후 수정·승인·게시·성과를 이어가는 것이 목표다. Rita에도 모듈로 사용할 수 있게 개발하고 있지만 이번 시험은 콘텐츠 운영 핵심에 집중한다.

현재 고객사 규칙/이력, 자료 기반 후보5개, 주간 선택3개/이유/담당/마감, 카드 초안/편집/저장/내보내기, 다음 주 복제를 로컬에서 검수했다. 이는 새로운 트렌드를 자동 발견하거나 AI가 새 글을 쓴 결과가 아니다. 결과가 실제 납품할 만큼 좋은지는 아직 사람 검수가 필요하다. 공개 서비스·실제 Instagram 자동 운영은 완료하지 않았다.

이번에 알고 싶은 것:
- 설명을 많이 듣지 않고 첫 결과를 만들 수 있는가?
- 대행사 직원으로서 고객사별 규칙과 주간 제작 묶음이 도움이 되는가?
- 자료 발췌를 카드로 다듬는 데 무엇을 얼마나 수정해야 하는가?
- 저장·재접속·다른 고객사 전환에서 혼란/유실이 있는가?

## 파일과 실행

공유 자료는 교수님이 지정한 Drive `조유경(소셜미디어)/outputs/Cora_유경_첫사용_2026-10-04/`에 있다. 실제 코드 원본은 같은 Drive의 `work/rita-agent-source/Cora/`다. 학생 컴퓨터에서 교수님과 같은 SQLite DB를 Drive로 동시에 열지 않는다.

교수님 컴퓨터에서 함께 시험한다면: 교수/AI가 별도 시험 데이터 경로로 서버를 준비한 뒤 브라우저에서 연다. 현재 서버는 종료 상태이므로 주소만 누르면 열리는 배포본이 아니다. 기존 운영 데이터·API 키로 시작하지 않는다.

학생 컴퓨터에서 시험한다면:
1. `Cora_첫사용_소스.zip`을 **동기화 폴더 밖**의 일반 작업 폴더에 푼다. 교수의 원본 checkout을 덮어쓰지 않는다. ZIP에는 소스/시험/설명서만 있으며 키·DB·의존성 설치본은 없다.
2. Node.js22.13 이상이 필요하다. 터미널에서 `node --version`을 확인한다. 설치/실행이20분 이상 막히면 오류를 남기고 교수와 해결한다. 개발 환경 설치 자체가 이번 평가의 주목적은 아니다.
3. 터미널에서 압축을 푼 폴더의 `Cora/apps/trend-hub`로 이동해 `node scripts/run-local.mjs`를 실행한다. 첫 실행은 npm 패키지를 인터넷에서 설치하므로 시간이 걸릴 수 있다.
4. 같은 컴퓨터의 브라우저에서 `http://127.0.0.1:3210/studio`를 연다. 이 주소는 다른 컴퓨터에서 교수의 앱에 접속하는 링크가 아니다. 포트 충돌은 기록하고 다른 앱을 임의 종료하지 않는다.
5. Cora 시험 계정을 만든다. 식별용 이메일과 다른 서비스에서 사용하지 않는10자 이상 비밀번호를 쓴다. 이메일 인증 메일은 현재 발송하지 않는다.
6. 첫 시험에는 키를 설정하지 않고 아래 **직접 원문 자료**를 사용한다. ‘AI로 카드 다시 쓰기’, AI 광고 생성, Instagram 연결·게시, 외부 자료 수집을 누르지 않는다. 이번 원문 경로는 AI가 필요 없다. AI 비용을 기술적으로 완전히 차단한 시험 모드는 아직 아니다. 교수 컴퓨터의 기존 LLM 환경에서는 AI 버튼을 누르면 유료 호출될 수 있다.
7. 종료는 실행한 터미널에서 Ctrl+C. 학생 컴퓨터의 시험 DB는 `Cora/apps/trend-hub/data/cora`에 남는다. DB/.env/키를 Drive·Git·ZIP에 다시 포함하지 않는다. 필요한 결과물은 앱의 JSON/PNG 내보내기로 제출한다.

이 실행 스크립트는 일반 로컬 경로다. 이번 추가 준비에서 학생 Mac/Windows 실제 설치·서버 실행을 검수했다고 기록하지 않았다. 설치 실패도 유용한 버그 증거다. 한 컴퓨터에서 혼자 첫 시험할 수 있지만 교수와 학생의 서로 다른 컴퓨터 간 실시간 공동작업은 아직 이 방식으로 제공되지 않는다.

주간 계획의 주 시작일은 월요일이다. 첫 시험은2026-10-05, 마감은2026-10-07, 복제 주는2026-10-12를 사용할 수 있다. 날짜가 지난 뒤 시험하면 실제 시험 주의 월요일/같은 주 마감으로 바꾼다. 담당자는 자신의 Cora 계정을 선택한다. 입력한3개 후보 모두에 선택 이유/담당/마감이 있어야 초안 생성 버튼이 작동한다.

새로고침 전에 **직접 자료 저장·주간 계획 저장**을 한다. 주간 화면의 미저장 입력은 아직 자동 복구함에 들어가지 않는다. 일반 브리프/카드 복구와 구분한다. 경고를 취소했을 때 입력이 유지되는지도 본다.

카드의 ‘내 검토 완료’는 고객의 승인이나 실제 게시 완료가 아니다. 카드 문구를 수정하고 저장하면 작성 중으로 바뀌어야 한다. 다음 주 복제는 계획만 만들며 기존 카드/승인 사본을 복제하지 않는다. 같은 원문을 선정했다면 겹침 안내가 보이는지 확인한다.
