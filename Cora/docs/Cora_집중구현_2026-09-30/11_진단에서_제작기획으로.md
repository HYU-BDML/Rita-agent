# 성과 진단에서 다음 콘텐츠 기획으로

2026-09-30. 유료 API 호출 0회.

성과 분석 결과에서 ‘다음 콘텐츠에서 시험할 가설’을 10~2,000자로 입력하고 ‘실험 기획 저장 후 제작실로’를 누른다. 분석 요약, 관찰 자료의 한계, 사용자가 적은 가설, 평가 시 확인할 조건을 하나의 소재로 저장한 뒤 카드 제작실의 자료 입력란에 넣는다.

저장 소재에는 원본 진단 ID와 생성 시각이 남는다. 본인의 저장된 수동 CSV 분석만 사용할 수 있으며 다른 계정의 진단 ID나 다른 종류의 자산은 거절한다. 표본이 부족한 자료도 가설 기획에는 활용할 수 있지만 부족한 근거를 숨기거나 성장 점수를 만들어 주지 않는다.

이 텍스트는 내부 기획이다. 공개용 완성 문안이 아니며 제작 전 브랜드 사실 자료와 독자, 비교 조건, 평가 기간을 사용자가 보완해야 한다. AI 생성이나 게시를 자동 실행하지 않는다. 현재 원문 분량과 문단이 많으면 기존 카드 구성 한도에 맞춰 편집해야 한다. 제작실 전환 시 저장하지 않은 기존 편집 내용이 있으면 기존 확인 절차를 따른다.

## 검증

프로덕션 빌드 통과. 전체 단위시험 348개 통과·기존 데이터 의존 시험 1개 제외. 신규 시험은 가설과 원본 한계의 보존, 잘못된 가설·자료 형식 거절을 확인한다. 브라우저/API 5개 경로에서 기존 CSV 품질 검증, 결과 유지, 잘못된 CSV 거절, 진단 출처를 보존한 기획 저장 및 제작실 전달, 다른 계정의 접근 거절을 확인했다.

재현: scripts/cora-experiment-proof.mjs와 tests/cora-experiment.test.ts. 증거는 검증기록/experiment-proof.json에 있다.

이 기능은 사람이 작성한 가설을 진단 자료와 연결하는 기능이다. AI 소재 추천, 공식 계정 동기화, 콘텐츠 성과 예측, 토픽 분석·XGBoost, 게시 후 자동 실험 평가까지 완료한 것은 아니다. E205는 부분 검증 상태를 유지한다.
