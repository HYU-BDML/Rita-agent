# 장면별 영상 길이와 선택형 자막

2026-09-30. 유료 API 호출 0회.

카드뉴스 편집에서 장면을 선택하고 ‘선택한 장면 길이 (초)’에 1~10초, ‘선택한 장면 자막’에 200자 이하 문구를 입력한다. 작업을 저장하면 장면 설정도 함께 보관된다. 카드 순서가 영상 순서이고 장면 추가·삭제·이동은 기존 카드 편집 흐름을 따른다. MP4 영상 만들기는 이 설정을 사용한다. 과거 작업은 장면당 3초·자막 없음으로 호환한다.

FFmpeg가 장면별 시간표를 바탕으로 1080×1920 H.264 영상을 만들고 mov_text 자막 트랙을 포함한다. 자막 없는 장면의 시간도 다음 자막 시작 시각에 반영한다. 영상 마지막 프레임을 보정해 지정한 총 길이를 유지한다.

**선택형 자막은 영상에 글자를 영구적으로 새기는 방식이 아니다.** 지원 재생기에서 자막을 켜야 한다. SNS 업로드 시 자막 트랙이 유지되지 않을 수 있으므로 SNS용 완성 자막 기능으로 표시하지 않는다. 음성·배경음악·전환 효과·단어별 강조·음성 길이에 맞춘 자동 장면 조절은 아직 없다. 현재 자막은 직접 입력한다.

## 검증

프로덕션 빌드 통과, 전체 단위시험 344개 통과·기존 데이터 의존 시험 1개 제외. 신규 타임라인 시험 2개는 시간 계산, 자막 없는 구간, 여러 줄 한글, 잘못된 길이, 저장 유효성 검사를 확인한다.

브라우저/API 및 미디어 검수 4개 경로 통과. 첫 장면 7초와 나머지 장면 3초로 실제 MP4를 생성했다. ffprobe로 총 22초·1080×1920 H.264 및 mov_text 트랙을 확인하고, ffmpeg로 0~7초의 두 줄 한글 자막을 다시 추출했다. 렌더 메타데이터가 시간표와 일치하며 비로그인 영상 다운로드는 거절된다.

재현: scripts/cora-timeline-proof.mjs. 검증기록/timeline-proof.json, timeline-media-probe.json, timeline-unit-tests.txt. 실제 결과물은 outputs의 증거/timeline/timeline.mp4에 있다. F039/F050/F055는 전체 Mirr 기능이 아닌 해당 부분의 구현으로 기록한다.
