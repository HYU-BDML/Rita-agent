# 기능 20개 추가 구현과 검증 결과

2026-09-30 Claude(Opus)와 보조 에이전트(Sonnet) 4개가 구현했다. 보조 에이전트는 새 파일만 만들었고, 화면 연결·공용 파일 수정·최종 검수·커밋은 Claude가 맡았다. 보조 에이전트가 보고한 통과 결과는 그대로 쓰지 않고, Claude가 별도 시험 폴더에서 단위시험과 검수 스크립트를 다시 실행해 확인했다.

## 구현한 기능

| 묶음 | 기능 | 화면 위치 |
|---|---|---|
| 블로그 개요 승인(Claude) | F061 조사→개요 승인→본문, F062 개요 중복 승인 방지, F019 기획 검토 후 제작(블로그만) | 작업실 › AI 글·대본 › 개요 먼저 승인하고 본문 쓰기 |
| 자산 라이브러리(에이전트 A) | F022 템플릿 즐겨찾기·재사용, F027 개인 템플릿, F095 로고 보관, F078 CTA 문구 보관함 | 자산 라이브러리 |
| 작업공간 설정(에이전트 B) | F007 아이디어 상태, F060 블로그 진행·기간 필터, F097 알림 설정, F099 제품 언어 | 아이디어 보드, 알림과 언어 설정 |
| 크레딧·결제(에이전트 C) | F101 체험·사용량, F103 크레딧 기록, F104 기능별 단가, F105 추가 크레딧, F102 구독 변경 | 사용량과 결제 |
| 입력·공개 화면(에이전트 D) | F004 PDF→카드뉴스, F005 YouTube→소재, F092 링크 페이지, F109 도움말·문의, F106 API 키와 REST 문서 | PDF·YouTube 가져오기, 링크 페이지와 API, /help, /api-docs, /l/주소 |

알림은 검토 요청·검토 결정·팀 초대·예약 작업 최종 실패·모의 게시 결과에서 생성된다. 공개 경로는 `/help`, `/api-docs`, `/l/주소`, `/api/v1/`만 정확히 열었고, 기존 운영자 전용 경로는 그대로 막혀 있다(단위시험으로 확인).

## 검증

Claude의 별도 시험 폴더에서 전체 단위시험 423개 중 422개가 통과했고, 기존 자료 의존 시험 1개는 이전과 같이 제외했다. 프로덕션 빌드도 통과했다. 새 DB의 서버에서 실행한 브라우저 검수 결과는 아래와 같다.

| 검수 | 결과 | 확인한 것 |
|---|---|---|
| outline | 통과(실제 AI 2회) | 개요 생성, 승인 전 본문 거절, 수정 후 1회 승인, 동시 본문 요청 1건만 생성, 화면에서 본문 열기 |
| integration | 통과 | 새 화면 4개 표시, 화면에서 템플릿 적용 후 저장, 검토·팀 알림이 상대 계정에 표시 |
| library | 통과 | 템플릿·로고·CTA 저장과 계정 격리, 교차 출처 차단 |
| settings | 통과 | 아이디어 상태 이동, 기간 필터, 언어·알림 설정 |
| billing | 통과 | 체험, 견적, 주문, 토스 키 없음 503, 금액 불일치 거절, 계정 격리 |
| inputs | 통과 | PDF 한글 추출, 링크 페이지 CSP·이스케이프, 클릭 제한, 문의, API 키 인증·폐기 |
| inputs-ui | 통과 | 화면에서 PDF 가져와 저장, 링크 페이지 공개, API 키 생성·폐기, 도움말 공개 |

outline 검수는 첫 실행에서 앞의 네 확인을 통과한 뒤 마지막 화면 단계에서 멈췄다. 원인은 API로 본문을 만든 뒤 화면을 다시 불러오지 않은 검수 스크립트였다. AI를 다시 부르지 않도록 스크립트를 고치고, 마지막 단계만 같은 계정으로 따로 확인했다.

## 이번 작업의 사고와 조치

Claude의 시험 폴더 동기화 명령(`rsync --delete-excluded`)이 공용 시험 폴더의 `node_modules`를 지워, 약 1분 동안 보조 에이전트의 시험이 실패할 수 있었다. 같은 잠금 파일로 즉시 다시 설치했고, 에이전트들에게 재실행을 알렸다. 이후 Claude의 시험은 `node_modules`를 보호하는 별도 폴더에서만 했다. 같은 작업 중 시험이 실패한 커밋(`0800222`)이 한 번 올라갔고 다음 커밋(`ccf6ccc`)에서 고쳤다. 그 뒤로는 시험 통과를 확인한 뒤에만 커밋했다.

## 남은 한계

- 로고는 보관만 하고 카드에 그리지 않는다. 템플릿 미리보기 썸네일이 없다.
- 크레딧 차감은 AI 생성 경로에 아직 연결하지 않았다. 요금제·팩 금액은 교수 확인이 필요한 임시값이다. 토스 결제창과 실제 테스트 결제는 테스트 키 발급 뒤에 한다.
- 이메일 알림은 Resend 키 발급 뒤에 실제로 확인한다. 기존 화면의 영어 번역은 하지 않았다.
- PDF 추출은 스캔본·암호화 파일·다단 배열을 처리하지 못하고, 실제 외부 PDF로 시험하지 않았다.
- YouTube는 영상 정보만 가져오고 자막은 사용자가 붙여 넣는다. 실제 API 호출은 하지 않았다.
- 요청 제한(API 키·링크 클릭·문의)은 서버 메모리에 있어 재시작하면 초기화되고 여러 서버에서는 공유되지 않는다.
