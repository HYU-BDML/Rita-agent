# 카드별 문자와 사진 설정, 실행 취소의 구현

2026-09-30 Claude(Opus) 구현. 유료 AI 호출 0회.

## 추가한 기능

제작실 오른쪽 “문자와 사진 설정”에서 선택한 카드 한 장의 문자 정렬(왼쪽·가운데·오른쪽), 강조할 단어, 자간(좁게 2부터 넓게 8까지), 본문 행간(1.3~2.0)을 정한다. 사진이 있는 카드에서는 사진 맞춤(영역 채우기 또는 사진 전체 보이기), 기준 위치(위·가운데·아래), 밝기(50~150%)를 정한다. 상단의 “실행 취소”와 “다시 실행” 버튼은 편집을 최대 50단계까지 되돌리며, 600ms 안에 이어진 입력은 한 단계로 묶는다.

카드 미리보기, PNG 내보내기, MP4 제작, 검토자 화면이 모두 같은 그리기 함수(`lib/cora/artwork.ts`)를 쓰므로 설정 하나가 네 곳에 같이 반영된다. 자간과 행간을 넓히면 줄바꿈 폭을 다시 계산하고, 넘치면 기존 규칙대로 본문 글자 크기를 줄인다. 강조 단어는 그 단어가 나오는 모든 자리를 브랜드 색(표지 카드에서는 밝은 주황)과 굵은 글씨로 바꾼다.

## 저장과 검증 규칙

설정은 카드마다 `style` 항목으로 저장한다. 서버는 허용한 값만 받고(정렬 3종, 강조 단어 40자, 자간 정수 -2~8, 행간 5종, 사진 맞춤 2종, 위치 3종, 밝기 0.5~1.5) 나머지는 400으로 거절한다. `style`이 없는 이전 작업은 그대로 열리고 기존 모양을 유지한다. 강조 단어의 HTML 특수문자는 SVG에 그대로 들어가지 않도록 변환한다.

## 검증

단위시험 `tests/cora-card-style.test.ts` 3개가 설정 검증, 이전 작업 호환, SVG 반영(정렬 좌표, 자간, 강조 tspan, 사진 맞춤, 밝기 필터), 특수문자 변환, 줄바꿈 재계산을 확인한다. 전체 단위시험은 372개 중 371개 통과했고, 기존 자료 의존 시험 1개는 이전과 같이 제외했다. 프로덕션 빌드도 통과했다.

브라우저 검수 `scripts/cora-card-style-proof.mjs`는 4개 경로를 통과했다(검증기록/card-style-proof.json). 정렬·강조·자간·행간의 미리보기 반영, 업로드한 사진의 맞춤·밝기 반영, 실행 취소·다시 실행과 단축키, 서버 저장과 잘못된 값 거절을 확인했다.

## 확인하지 못한 부분과 한계

브라우저 자동화에서는 Mac의 Cmd+Z 입력이 페이지에 전달되지 않아 Ctrl+Z로만 단축키를 확인했다. 코드는 두 키를 같은 방식으로 처리하지만, 실제 Mac 키보드의 Cmd+Z 동작은 사람이 확인해야 한다. 입력칸 안의 Cmd+Z·Ctrl+Z는 앱의 실행 취소가 아니라 입력칸 자체의 되돌리기로 동작한다. 강조 단어가 줄바꿈 경계에 걸리면 그 자리는 강조되지 않으며, 강조 단어는 카드당 하나다. 레이어 선택·순서·복제(F029)와 요소 추가(F028)는 이번 범위에 없다.
