# 119개 기능 원장의 3회 전수 점검 결과

2026-09-30 Claude(Opus) 점검. 사용자 요청: Mirr 기능 109개를 빠짐없이 가져오고, 구현했다고 표시한 기능이 실제로 있고 문제없이 동작하는지 두세 번 확인한다.

## 결론

Mirr 원본 기능대장 109개는 원장 F001~F109에 이름까지 같게 모두 들어 있고, 추가 채택 기능 10개(E201~E210)와 합쳐 119행이다. 구현했다고 표시한 53개 행 가운데 50개는 코드와 증거가 표시와 맞았고, 3개는 표시가 실제보다 높아 낮췄다. 브라우저 검수 스크립트 16개는 1차에서 15개, 2차에서 14개를 새 DB로 다시 실행해 모두 통과했다. 2차에서 1개가 멈춘 원인은 로컬 가입 제한(1분 15회)이었고, 단독 재실행에서 통과했다.

점검 뒤 원장 상태는 브라우저 검증됨 4개, 부분 검증 30개, 부분 구현 20개, 미구현 65개다. Mirr 기능을 “전부 완성”한 상태는 아니며, 미구현 65개가 남아 있다.

## 1차 점검: 원본 대조와 전체 재실행

`scripts/audit_ledger.py`로 `docs/Mirr_기능대장.csv` 109행의 ID와 기능 이름을 원장과 대조했고, 빠진 행과 이름 불일치는 0건이었다. 같은 스크립트로 구현 표시 행마다 인용한 문서·검수 결과 파일이 실제로 있는지와 검수 결과가 통과인지를 확인했다.

같은 날 새 DB로 프로덕션 빌드, 단위시험, 브라우저 검수 15개를 실행했다. 빌드는 통과했고 단위시험은 369개 중 368개 통과(기존 자료 의존 1개 제외)였다. 검수 15개(studio·access·experiment·operations·publication·quality·queue·review·scheduler·srt·team·text-edit·timeline·design·sprint)가 모두 통과했다. design·sprint 검수는 실제 AI를 3회 호출했다(cora_test 경로, 실행당 3건 규칙 이내).

## 2차 점검: 코드 직접 확인과 표시 정정

증거가 “기존 Cora 브라우저 증거 참조”라는 일반 문구뿐이던 9개 행과, 검수 파일 인용 없이 “브라우저 검증됨”으로 표시된 4개 행을 코드와 검수 스크립트로 직접 확인했다.

| ID | 기능 | 확인한 사실 | 조치 |
|---|---|---|---|
| F028 | 텍스트·이미지·로고·영상 요소 추가 | 카드별 제목·본문·사진 1장 교체만 있고 요소 추가 코드는 없음 | 부분 구현에서 미구현으로 정정 |
| F033 | 이미지 속성 | 사진 위치·맞춤·밝기 조절 코드가 없었음 | 미구현으로 정정한 뒤 이번에 구현해 부분 검증 |

같은 차수에서 카드 편집기 확장(F031 문자 강조·정렬, F032 자간·행간, F033 이미지 속성, F034 실행 취소)을 구현했다(17_카드_문자와_사진_설정.md). 그 뒤 새 DB로 AI를 부르지 않는 검수 14개(새 card-style 포함)를 다시 실행했고, 13개가 바로 통과했다. scheduler 검수는 앞선 검수들이 1분 안에 가입을 여러 번 하면서 로컬 가입 제한에 걸려 멈췄고, 서버를 다시 시작해 단독 실행했을 때 통과했다. 이 제한은 의도한 보호 장치이므로 풀지 않았다. 대신 검수를 연달아 실행할 때는 1분 간격을 두거나 서버를 새로 띄워야 한다.

## 3차 점검: 정정 후 원장 재대조

정정과 새 구현을 원장에 반영한 뒤 `scripts/audit_ledger.py`를 다시 실행했다. Mirr 누락 0건, 인용 파일 누락 0건(이 문서 작성 후), 실패한 검수 인용 0건, 일반 문구만 있는 행 0건이다.

외부 입력 없이 이어서 구현할 수 있는 기능은 다음과 같다. 템플릿 즐겨찾기·개인 템플릿(F022·F027), 레이어·요소 추가(F028·F029), 아이디어 상태(F007), 기획 검토 후 제작과 블로그 개요 승인(F019·F061·F062), 블로그 필터(F060), 새 예약 작성·재게시(F068·F070), CTA 보관함(F078), 로고 보관(F095), 알림 설정(F097), 제품 언어(F099), 기간 비교·지표 정규화(F087·F088), 크레딧 기록·단가(F103·F104), 링크 페이지(F092), 도움말(F109), PDF→카드뉴스(F004), 영상 비율·장면 충돌·자막 강조·템플릿(F038·F044·F045·F046·F051·F052·F054), API 키 문서(F106)가 여기에 속한다.

## 재현 방법

Cora 폴더에서 `python3 scripts/audit_ledger.py`를 실행하면 대조 결과가 나오고, 불일치가 있으면 종료 코드 1이 나온다. 브라우저 검수는 `apps/trend-hub/scripts/cora-*-proof.mjs`이며 실행 방법은 02_실행과검증.md에 있다. 이번 재실행 결과 가운데 studio·design·sprint·card-style 검수 결과는 검증기록 폴더에 저장했다.
