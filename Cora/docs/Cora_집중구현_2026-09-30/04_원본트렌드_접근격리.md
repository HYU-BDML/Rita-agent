# 원본 Trend 접근 격리

2026-09-30 자동 개발 실행. AI 생성 호출 0회.

원본 Trend의 데이터는 사용자별로 나뉘지 않은 공용 저장소다. 이제 지정된 운영자만 API와 서버 화면에 접근한다. 일반 Cora 회원가입만으로 공용 자료를 보거나 수집·변경할 수 없다. 원본 자료나 코드 기능을 삭제하지 않았다. 별도의 Cora 소재 수집·생성 API는 기존 사용자별 인증 경로를 유지한다.

- 서버 환경의 `CORA_LEGACY_OPERATOR_ID`가 없으면 원본 경로는 503으로 차단한다.
- 지정된 경우 실제 Cora 세션을 확인한다. 무인증 401, 다른 사용자 403, 운영자만 통과한다.
- 변경 요청은 기존 Cora Origin 검증도 통과해야 한다.
- 서버가 직접 출력하는 후보·설정 화면과 Next 데이터 요청도 보호한다. 쿠키 문자열의 존재만으로 허용하지 않는다.
- 로그아웃으로 폐기한 세션은 즉시 거부한다. 사용자 지정 헤더로 운영자 역할을 전달하지 않는다.

운영자가 필요하면 로컬 Cora 계정의 사용자 ID를 확인해 서버 환경 변수로 지정한다. 첫 가입자를 자동으로 운영자로 승격하지 않는다. 기존 cron의 서버 간 호출은 운영자 세션을 전달하지 않으므로 현재 차단된다. 새 스케줄러와 제한된 서비스 인증을 구현하기 전까지 그대로 공개하지 않는다.

검수: 프로덕션 서버에서 기존 API 11경로 전체의 기본 차단, 무인증/다른 사용자 차단, 운영자 읽기 허용, 교차 출처 변경 차단, 위조 쿠키·미들웨어 우회 헤더 거부, 서버 화면·Next 데이터 보호, Cora 작업실 유지, 로그아웃 후 차단을 검증해 통과했다. `scripts/cora-access-proof.mjs`로 재현할 수 있다. 네트워크 수집·AI 생성 등 유료 원본 작업은 실행하지 않는다.

이 변경만으로 상용 보안 검토를 완료한 것은 아니다. 팀별 원본 데이터 분리, 운영 인증·백업 복원, 분산 제한, 잔여 의존성 보안은 별도 미완성 항목이다.

최종 결과: 프로덕션 빌드 통과, 단위 시험 333개 통과·기존 데이터 의존 1개 제외, 접근 통합 시험 8개 묶음 통과, Cora 운영 브라우저 회귀 7개 통과. 단위 시험 대부분은 기존 Trend 시험이며 신규 접근 정책 시험은 2개다.
