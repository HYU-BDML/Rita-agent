# 수동 성과 자료의 품질 검증

2026-09-30. 유료 API 호출 0회.

성과 CSV 분석에 입력 행 수, 중복 제외 후 기록 수, 중복 제외 행 수, 저장률 계산 가능 행 수, 항목별 결측 수를 추가했다. 화면과 저장된 분석 결과에 함께 남는다. 빈칸은 0으로 대체하지 않는다.

날짜·제목·도달·저장·좋아요·댓글이 모두 동일한 행은 첫 행만 집계한다. 게시물 ID로 판별하는 방식은 아니므로 실제로 서로 다른 게시물이 모든 값까지 같다면 입력 자료를 구분해 보완해야 한다. 원본 행은 결과 표에 남고 제외 여부를 표시한다. 저장 수가 도달보다 큰 행은 원값을 보존하고 측정 정의를 확인할 때까지 저장률 계산에서 제외한다. 이는 해당 플랫폼에서 그런 값이 절대로 불가능하다는 주장이 아니다.

중복 열 이름, 헤더와 다른 열 수, 음수·소수·지수·16진수·안전한 정수 범위를 벗어난 지표는 거절한다. 수치 입력은 10진 정수 또는 빈칸이다. 가중 저장률은 계산 가능한 행의 저장 합계 ÷ 도달 합계이며, 제외된 행을 분모에 섞지 않는다. 비교 가능한 행이 적으면 점수를 제시하지 않고 자료 보완을 안내한다.

## 검증

프로덕션 빌드 통과. 전체 단위시험 347개 통과·기존 데이터 의존 시험 1개 제외. 신규 시험 3개는 중복과 분모, 모호한 열·수치 입력, 모순된 측정값과 결측/0 구분을 확인했다. 브라우저/API 시험 3개는 화면의 제외 내역과 1.90% 가중 저장률, 재접속 후 품질 정보 유지, 잘못된 열 수의 API 거절을 확인했다.

재현: tests/cora-analytics-quality.test.ts 및 scripts/cora-quality-proof.mjs. 검증기록/quality-proof.json 참조.

공식 계정 연동, 검증된 계정 성장 점수, 인과 효과 추정, 토픽 분석·XGBoost 모델, 다음 콘텐츠 자동 생성 연결은 이번 변경에 포함하지 않는다. E205는 부분 검증 상태를 유지한다.
