# API 발급 없이 만들 수 있는 기능의 마무리

2026-09-30 Claude(Opus)와 보조 에이전트(Sonnet) 4개가 구현했다. 보조 에이전트는 정해진 파일만 만들거나 고쳤고, 화면 연결·공용 파일 수정·재검수·커밋은 Claude가 맡았다. 보조 에이전트가 보고한 통과 결과는 그대로 쓰지 않고, 마지막 커밋 상태에 해당 묶음 파일만 얹은 별도 폴더에서 Claude가 전체 시험과 브라우저 검수를 다시 실행했다.

## 결론

원장 119개 가운데 미구현은 이번 차수 전 45개에서 20개로 줄었고, 남은 20개는 모두 외부 API나 계정이 있어야 동작한다. 새 API 발급 없이 만들 수 있는 기능은 이번 차수로 모두 구현했다. 원장 상태는 브라우저 검증됨 4개, 부분 검증 73개, 부분 구현 22개, 미구현 20개다. 전체 단위시험은 474개 중 473개가 통과했고, 기존 자료 의존 시험 1개는 이전과 같이 제외했다.

## 긴 영상을 목적에 맞는 숏츠로 나누는 기능

사용자 요청에 따라 추가했다. “긴 영상 → 숏츠” 화면에서 긴 영상과 자막을 올리고 목적을 고르면 구간을 추천한다. 목적은 핵심 요약·웃긴 순간·감동·방법·제품 소개·궁금증 유발 가운데 고르거나 직접 입력한다.

- 추천은 두 방식이다. AI 추천은 자막 전체(길면 고르게 표본)를 읽고 구간마다 제목·첫 화면 문구·강조 단어·이유·점수를 낸다. 규칙 추천은 AI 없이 목적 단어, 질문·감탄, 말의 밀도로 점수를 매긴다.
- 모든 구간은 자막 경계에 맞춰 문장 중간에서 끊기지 않게 조정하고, 정한 길이(예: 12~20초)를 맞추며, 서로 겹치지 않게 고른다. AI가 자막에 없는 번호나 없는 강조 단어를 내면 버린다.
- 점수가 높은 구간부터 보여 주고, 70점 미만은 “약한 추천”으로 표시해 기본 선택에서 뺀다. 첫 검수에서 AI가 웃긴 내용이 없는 도입부(55점)를 추천했고, 화면이 시간 순서로 보여 줘 그 구간이 맨 위에 왔다. 이 문제를 발견해 점수 순 정렬과 약한 추천 표시로 고쳤다.
- 사람이 제목·첫 화면 문구·강조 단어·시작과 끝 시각을 고친 뒤 만들면, 세로 1080×1920 숏츠가 된다. 세로 맞춤(가운데 잘라 채우기 또는 흐린 배경), 첫 2초 도입 문구, 강조 단어가 색칠된 자막, 목소리 아래에 깔리는 배경음악(크기·페이드 조절)을 선택한다.
- 배경음악은 사용자가 올린 파일만 쓰며 이용 조건 메모가 필수다. 자막이 없는 영상은 whisper.cpp를 설치하고 경로를 지정하면 로컬에서 받아쓸 수 있다. 이 컴퓨터에는 설치돼 있지 않아 받아쓰기 실제 실행은 확인하지 못했다.
- 만든 숏츠는 내려받아 올리거나 게시 준비로 이어간다. Instagram 공식 API 연결은 아직 이미지만 다루므로 릴스 실제 게시는 Meta 앱 발급 뒤 확장해야 한다.

브라우저 검수(검증기록/shorts-proof.json)에서 90초 영상을 올려 “방법·팁” 목적의 규칙 추천이 방법 구간과 겹치는 것을 확인했다. “웃긴 순간” 목적의 실제 AI 추천(cora_test 1회)은 가장 높은 점수의 구간으로 실제 웃긴 구간(30~44.8초)을 골랐다. 그 구간을 흐린 배경·도입 문구·강조 자막·배경음악이 들어간 1080×1920 숏츠로 만들어 ffprobe로 크기·길이·소리를 확인했다.

## 이번 작업의 사고

공용 의존성 폴더(`/var/folders/.../cora-runtime-bb3q2_1b`)가 작업 중 운영체제 임시 폴더 정리로 사라졌다. 이 세션의 작업 폴더 안에 의존성을 다시 설치해 이어갔다. 다음 작업자도 임시 폴더에 의존하지 말고 `node scripts/run-local.mjs`나 별도 폴더에서 `npm ci`로 준비해야 한다.
