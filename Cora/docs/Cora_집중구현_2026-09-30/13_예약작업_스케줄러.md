# 예약 작업 스케줄러의 영구 큐와 백그라운드 실행

2026-09-30 Claude 구현. 유료 AI 호출 0회, 실제 외부 게시 요청 0회.

## 추가한 기능

게시 준비함의 모의 큐 작업에 ‘자동 진행 예약’ 버튼을 추가했다. 예약하면 희망 게시 시각이 미래일 때는 그 시각부터, 아니면 즉시 10초 간격으로 모의 접수와 결과 대조를 반복하고, 모의 완료·실패·중단·취소 상태에 이르면 예약이 스스로 종료된다. 자동화 레시피 탭에는 ‘주기 실행 예약’(매일·매주·2주·30일)을 추가했으며, 예약별 ‘AI 자동 호출 허용’과 서버의 `CORA_SCHEDULER_AI=1`이 모두 켜져야 실제 생성을 호출하고, 기본값에서는 건너뜀 사유를 실행 기록에 남긴다.

예약 작업과 실행 기록은 같은 SQLite 파일의 `scheduled_jobs`·`scheduled_runs` 표에 저장되어 서버 재시작 후에도 유지된다. 백그라운드 실행은 `CORA_SCHEDULER=1`일 때 Next.js instrumentation 훅에서 프로세스당 한 번 시작하며(기본 15초 간격, `CORA_SCHEDULER_TICK_MS`로 조정), 꺼져 있으면 화면의 ‘실행 시각이 된 예약 지금 실행’ 버튼으로만 진행한다.

## 실행 규칙

- 같은 사용자·같은 종류·같은 대상의 예약은 하나만 존재한다(부분 고유 색인). 다시 등록하면 기존 예약 ID를 돌려준다.
- 실행 전 60초 임대(lease)를 잡는다. 두 DB 연결이 동시에 실행해도 같은 작업을 한 번만 처리한다. 임대가 만료된 작업은 `lease_expired`로 기록하고 실패 1회로 센다.
- 실패는 1회당 60초×2ⁿ(반복 간격 이내)만큼 늦춰 재시도하고, 기본 3회 실패하면 `failed`로 멈춘다. 사용자가 ‘다시 시작’을 누르면 시도 횟수가 0으로 돌아간다. 실패 원인 문구는 300자 이내로 자르고 공급자 오류 원문은 넣지 않는다.
- 반복 작업이 늦게 실행되면 놓친 회차를 몰아서 실행하지 않고 다음 정기 시각으로 건너뛴다.
- 모의 게시 자동 진행은 큐의 `unknown` 상태 중 접수 ID가 없는 경우(전송 결과 불명)를 종료 상태로 취급해 재전송하지 않는다.
- 다른 계정은 예약을 조회·일시정지·취소·실행 기록 조회할 수 없고, 남의 큐 작업이나 레시피를 대상으로 예약할 수 없다. 교차 출처 POST는 403이다.
- 레시피 예약 실행은 하루 10회 로컬 생성 한도를 그대로 따르며, 한도에 걸리면 건너뛴다. 레시피가 삭제되면 예약이 종료된다.

## 검증

단위시험 `tests/cora-scheduler.test.ts` 8개(중복 방지·계정 격리·파일 재열기 유지·임대 만료·재시도 상한·재개·건너뜀·1회성 종료·놓친 회차 처리·모의 게시 종료·AI 게이트 3단·두 연결 동시 실행)를 포함해 전체 358개 중 357개 통과, 기존 자료 의존 1개 제외. 프로덕션 빌드 통과.

브라우저 검수 `scripts/cora-scheduler-proof.mjs` 6개 경로 통과(검증기록/scheduler-proof.json): 화면 예약·중복 등록·백그라운드 꺼짐 표시, 타 계정 차단·교차 출처 거부, 지금 실행 1회 전송·재실행 무동작, 페이지를 다시 불러온 뒤 유지·10초 뒤 모의 완료·예약 자동 종료·실행 기록 표시, 레시피 예약이 AI 미허용으로 건너뛰고 다음 주로 이동·생성 실행 기록 0건, AI 허용·일시정지·재개·취소 화면 조작.

백그라운드 루프는 `CORA_SCHEDULER=1 CORA_SCHEDULER_TICK_MS=2000`으로 띄운 별도 서버에서 버튼 없이 12.5초 안에 모의 접수→모의 완료→예약 종료까지 진행하는 것을 API 조회로 확인했다(scheduler-background-check 로그는 임시 폴더에만 있었으며 수치는 이 문서에 기록).

## 아직 완료하지 않은 범위

실제 공급자 게시는 여전히 연결하지 않았다. 백그라운드 루프는 단일 프로세스용이며 다중 서버 배포용 전용 워커가 아니다. 자연어 주기 해석(“매주 월요일 9시”)은 없고 선택식 간격만 지원한다. 예약 실행으로 만든 AI 결과의 브라우저 검수는 유료 호출이라 하지 않았다(단위시험에서 주입한 생성 함수로 검증). Mirr의 자동화 예시 템플릿 3종(F065)은 미구현이다.
