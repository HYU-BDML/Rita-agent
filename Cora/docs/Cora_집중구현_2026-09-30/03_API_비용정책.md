# Cora API 사용 정책

사용자 지시: 개발·반복 시험은 저렴한 모델로 최대한 진행하고, 본격적인 활용에서 필요한 작업만 고급 모델로 전환한다.

- 기본 시험: `cora_test` → `deepseek-flash`. 공식 모델 목록과 실제 카드 2장 JSON 생성 성공 확인.
- 선택적 품질 모드: `CORA_LLM_TIER=quality`. 개인 게이트웨이의 `cora_quality` 경로를 사용한다. 자동 전환 없음.
- 공통: 캐시 사용, 자동 재시도 0, Cora 기존 24시간 10회 사용자별 시험 한도 유지. 후속 자동 개발은 실행당 실제 생성 시험 최대 3회 유지.
- 키는 기존 llmgw 환경에서 읽는다. 제공한 RTF에서 공급자 정보만 확인했으며 원문·키를 출력하거나 GitHub에 넣지 않았다. RTF에 나온 모든 공급자의 연결 성공을 뜻하지 않는다.
- 설정은 `python3 scripts/setup-cora-llm.py`로 Cora 경로만 추가한다. 다른 프로젝트의 기본 모델/경로는 그대로 둔다.
- 실제 호출 금액은 현재 브리지에서 계측되지 않아 미확인이다. 공급자 공식 가격은 시간대·캐시 여부에 따라 다르다. 단가를 임의로 고정해 청구액으로 표시하지 않는다.

확인 자료: https://api-docs.deepseek.com/quick_start/pricing/ (2026-09-30). Flash가 Pro보다 저렴한 공식 요금 확인.

검증: 정책 단위 시험 3개 통과(기본 시험 경로, 명시적 품질 경로, 잘못된 모드/없는 모델 차단). 실제 Flash 카드 2장 JSON 생성 통과. 고가 모델 추가 호출 없이 확인했다.
