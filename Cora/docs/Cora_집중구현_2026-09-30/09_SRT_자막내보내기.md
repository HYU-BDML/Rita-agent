# SRT 자막 내보내기

2026-09-30. 유료 API 호출 0회.

제작실의 ‘편집 중인 SRT 자막 다운로드’는 현재 장면 길이와 자막으로 UTF-8 SRT 파일을 만든다. MP4 렌더 없이 사용할 수 있다. 자막이 하나도 없으면 안내하며 빈 파일을 만들지 않는다. 현재 편집 내용이므로 기존에 렌더한 영상과 달라질 수 있음을 화면에 표시한다.

운영 화면 → 자산 보관함 → 영상의 ‘영상에 사용한 SRT 다운로드’는 해당 렌더 당시의 서버 자막 파일을 내려받는다. 이후 편집한 문구가 이 파일을 덮어쓰지 않는다. 자막이 있는 렌더 완료 영상에만 링크를 표시한다.

다운로드 API는 로그인과 영상 소유권을 검사한다. mp4와 srt만 허용하며 임의 파일 경로를 받지 않는다. 비로그인은 401, 다른 소유자의 영상은 404, 지원하지 않는 파일 형식은 400으로 응답한다. 자막 없는 영상이나 사라진 파일은 404로 처리한다.

## 검증

프로덕션 빌드 통과, 기존 전체 단위시험 344개 통과·데이터 의존 시험 1개 제외. 신규 브라우저/API/미디어 검수 7개 경로 통과: 장면 저장, 편집기 SRT 다운로드, 실제 MP4 생성, ffprobe·ffmpeg로 길이와 한글 자막 확인, 파일 내용 일치·권한·형식 제한, 영상 메타데이터·소유권, 편집 후 과거 영상 자막 보존.

재현 스크립트는 scripts/cora-srt-proof.mjs이며 검증기록/srt-proof.json에 결과를 저장했다. 실제 UTF-8 파일은 outputs의 증거/srt/editor.srt와 rendered.srt에 있다.

선택형 자막 및 SRT 파일 내보내기까지의 구현이다. SNS 자동 자막 업로드, 영상에 영구적으로 새기는 자막, 자동 음성 인식, 핵심어 강조는 아직 없다. F055의 전환·차트 기능도 미구현 상태를 유지한다.
