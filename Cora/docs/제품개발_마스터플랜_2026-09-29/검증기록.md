## 실제로 실행하지 않은 검증

- 브라우저 화면의 실제 렌더·모바일·시각 접근성 검수. 이번HTML 검증은 구조와 상호작용 로직 범위다.
- 신규 제품의 개발·배포·로그인·SNS연결·앱심사·결제·게시·영상렌더.
- 실제 고객 데이터 수집·사람 코딩·XGBoost/토픽 모델 학습·성능 평가·성장 효과 실험.
- 논문 전문/부록 전체 검토·재현, 모든 경쟁 서비스의 유료 동일과제 비교.

JSON 계약은 설계용이며 실행 가능한 SQL migration/OpenAPI 완제품이 아니다. 참조 검사는 서비스의 보안·격리·올바른 데이터처리까지 증명하지 않는다. 개발 단계에서12개 E2E와 실제 고객 작업을 별도로 통과해야 한다.

## 인계 패키지

ZIP에는 새 마스터플랜과 연결된 기존 조사 파일들을 상대경로가 유지되도록 포함했다. `제품개발_마스터플랜_2026-09-29/00_여기부터.md` 또는 같은 폴더의 `개발계획.html`부터 읽는다. 이전 전략 문서는 배경이며 최신 범위·예산은 새01·07을 따른다. ZIP 자체를 다시 다운로드하는 링크는 추출 폴더에 ZIP을 함께 두지 않으면 작동하지 않을 수 있다.

기존 Claude 프로젝트·배포·원본 산출물은 이번 설계 작성에서 변경하지 않았다.

## 바이브 코딩 역할 보완

11 문서와 탐색 탭을 추가했다. 기능110개는 유지했다. 원문·통합본·HTML·ZIP을 갱신하고 로컬 링크/구조 검사와10개 검색·탐색 로직 검사를 다시 통과했다. 개발자24~40시간은 좁은R1의 상태가 양호할 때라는 조건을 유지했다. 측정 역할을 본인이 맡는 현금 예산 시나리오는396~554만원이며, 원래 계획468~650만원에서 하한72만원/상한96만원을 제외한 값이다. 본인 노동과 실제 가용시간은 별도다. 신규 제품을 구현하거나 사용자 역량을 실측한 것은 아니다.
