# 제품 결정사항

## 2026-09-29: 첫 고객 확정

사용자가 확정한 첫 고객은 **여러 브랜드의 SNS 콘텐츠를 정기적으로 제작하는 소규모 대행사**다.

- 핵심 업무: 고객사별 소재 선정 → 제작 → 수정 → 승인 → 예약 발행 → 성과 보고.
- 기능과 UI 평가 기준: 이 업무의 반복 작업과 혼선을 얼마나 줄이는가.
- 우선 설계 대상: 대행사 운영자·제작 담당자·승인하는 고객사 담당자.
- 다른 고객군의 요구는 첫 고객의 핵심 흐름을 완성한 뒤 확장한다.
- 2~10명 규모, 고객사 3~15개는 인터뷰 모집 가설이며 확정된 고객 조건이 아니다.
- 실제 업무 병목, 지불 의사, 시간 절감 효과는 별도로 검증한다.

이 결정은 이전 문서와 화면 시안의 ‘첫 고객 추천/가설’ 표기보다 우선한다. 기존 Claude 프로젝트와 서비스는 보존한다.
