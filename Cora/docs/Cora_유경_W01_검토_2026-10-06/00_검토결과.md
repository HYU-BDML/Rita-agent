**이번에 수행한 1주차의 핵심 과제(모의 전체 흐름·YouTube 주소 5건·작은 패치)는 완료로 인정할 수 있다. 학생 패치를 Cora에 적용했고 관련 시험·타입 검사·빌드·화면 검사를 통과했다.** 기능 동작과 콘텐츠 품질의 차이를 발견한 점이 이번 제출의 가장 큰 가치다. Cora 전체 출시나 실제 게시·성장 성능 검증 완료를 뜻하지 않는다.

## 1. 무엇을 확인했는가

총11개 파일: 요약/YouTube 기록 Markdown·HTML4개, 패치/설명2개, 화면 캡처5개. 학생 원본을 수정하지 않았다. 검토 기준은 공유폴더 `Cora_공동작업/무료API_판단과_조유경_첫3주.md`의 이번 수행 과제와 실제 제출이다. 최신 집중 출시10주 과제/2시간 워크북의 결과를 이 제출로 대신 채우지 않는다.

주소5번은 **실제 삭제된 영상 대신 존재하지 않는 ID**로 한 대체 시험이다. 재생목록 주소는 **목록 전체가 아닌 v=의 영상1개**다. 이 두 사실을 기능 지원/검증 범위에 그대로 반영한다. 학생의 정상 결과는 소프트웨어 동작 관찰이며 영상 이해·카드 완성도·추천 품질의 통과 증거가 아니다.

## 2. 채택한 수정과 검수

자료가 짧아 초안이 없는데도 “제목과 설명만 사용했습니다”라고 보이던 안내를 고쳤다. 충분한 자료/자막 여부와 **초안을 만들 수 있는지**를 구분하여 안내한다. 자료 부족 시 자막 텍스트를 직접 붙여 넣도록 설명한다. 자료 부족 기준(80자), 자막 다운로드 제한, 권한/요청 제한/초안 생성 동작은 바꾸지 않았다. Shorts뿐 아니라 짧은 자료에 공통 적용된다.

학생 원본 패치: `02_패치/W01_youtube-shorts-note.patch` (원본 패치 식별자 b00aeca).

## 3. 제출에서 얻은 개발 우선순위

1. **고객사에 납품할 수 있는 내용인가.** 학생은 카드가 만들어져도 내용 대부분이 홍보·링크·이메일이면 쓸 수 없다는 문제를 발견했다. 단순 생성 성공 대신 핵심 주장/근거/고객사 적합성/수정량을 측정해야 한다. 원문은 보존하고, 제작에 쓸 근거와 홍보/연락 문구를 분리해 사람이 확인하는 개선이 필요하다. 무조건 링크나 숫자를 삭제하면 근거도 잃을 수 있다. YouTube 전용 정제는 보존된 labs 개선 목록에 두고, 집중 출시의 자료→주간 판단→카드 품질 시험에도 이 관찰을 반영한다. 이번에는 정제 기능을 구현하지 않았다.
2. **계정이 바뀌었음을 명확히 알려야 한다.** 같은 브라우저 탭의 로그인 쿠키 공유는 일반적인 동작이다. 화면은 제작자로 보이지만 요청은 검토자로 처리되는 혼란/저장 실패가 제품 문제다. 계정 전환 감지, 저장 전 확인, 미저장 초안 보존을 함께 검수한다. 제출만으로 서버 권한 우회나 데이터 유실이 확인된 것은 아니다. 당장은 검토자를 시크릿 창/별도 브라우저로 시험한다.
3. **재현 가능한 오류를 먼저 고친다.** 뒤로가기·초안 수정 불가·한글 잘림은 정확한 메뉴/자료/화면 크기/순서가 있어야 수정할 수 있다. 메뉴·영상 제목/길이·주소 안내도 별도 개선 목록에 남긴다. labs 메뉴 숨김은 집중 출시 결정이며 기본 모드에서 안 보이는 것 자체는 결함이 아니다. 시험 안내에 labs 설정이 빠진 것은 보완 대상이다.

세부 상태는 `01_수정목록.csv`에 기록했다. 이 목록은 새119개 원장이나 출시 완료표가 아니다. 아직 확인되지 않은 문제를 확인 완료로 표시하지 않는다.

## 4. 유경에게 요청할 짧은 보완

1주차 전체를 다시 하지 않는다. 다음 과제 시작 전 **20~30분 상한**으로 이미 만든 결과에서만 보완한다.

- 남아 있는 작업이 있으면 PNG ZIP·작업JSON과 수정 후 안내 캡처1장을 제출. 없다면 “저장 파일 없음/이번에 확인하지 못함”으로 기록하고 재제작하지 않는다.
- 뒤로가기/초안 수정/한글 잘림 중 가장 불편했던1건: 사용 메뉴·입력 예시·클릭 순서·기대/실제·화면 크기·캡처·재현 횟수. 재현되지 않으면 그 사실을 적는다.
- 설치/실사용/AI 도움/대기 시간을 기억 범위로 적되, 기억이 없으면 추정 숫자를 만들지 않는다.
- 5번 결과 이름을 “존재하지 않는 ID 대체 시험”, 4번을 “목록 매개변수를 포함한 단일 영상 시험”으로 명확히 한다.

파일은 기존 `outputs/조유경_10주/W01/`에 두면 된다. 키·비밀번호·사용자 DB는 제출하지 않는다. 전달용 문구는 `02_유경에게_피드백.md`에 있다.
